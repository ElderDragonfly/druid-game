# Попадание по друиду: два боковых ракурса

Эти два принятых рисунка сохранены без изменений. Теперь к ним подключены [остальные шесть направлений](../druid-hit-eight-way-v1/README.md); у основного друида доступны все восемь реакций.

- [Реакция влево](hit-left-preview.gif) / [кадры](hit-left-keyframes.png).
- [Реакция вправо](hit-right-preview.gif) / [кадры](hit-right-keyframes.png).

Это ракурс, в который смотрит друид, а не сторона прилетевшего удара. Корпус немного сгибается от удара в живот; затем герой выпрямляется. Отбрасывания и изменения HP нет. Посох остаётся в анатомической левой руке; ракурсы отдельно нарисованы, не отражены.

Прозрачные листы `hit-{left,right}-512x384.png`: пять кадров по 512×384, фигура в исходном масштабе 256×320 со смещением (128,40). Фазы: исходная стойка → начало сгибания → пик → выпрямление → исходная стойка. Игровые длительности **40/70/120/100/70 мс**, всего **400 мс**. GIF удерживают стойку дольше только для просмотра.

Новые позы нарисованы по двум принятым игровым idle в [source-poses.png](source-poses.png). `scripts/prepare-druid-hit-sides.py` изолирует ячейки, применяет одну общую регистрацию размеров на ракурс, совмещает стопы и переносит существующую палитру. Нижние части сапог сохранены из исходной стойки по отдельным маскам `boot-mask-*`, чтобы ноги не скользили. Первый и последний кадр дословно совпадают с прежними PNG; старые файлы не менялись. Полупрозрачной каймы нет, игровой фильтр NEAREST. Масштаб физического тела и отрисовки прежний.

`DruidHitReaction` имеет отдельный таймер, `druidHitArt` загружает рисунки; ссылки задаются в `CharacterDefinition.game.hits`. Попадание прерывает каст и ходьбу, сохраняет направление на время реакции; зажатые клавиши снова действуют после её окончания. Для ещё не нарисованных ракурсов остаются их прежняя стойка и пауза той же длины, без бокового разворота. Дальнейшие ракурсы можно подключать через ту же таблицу.

Волк проверяет дистанцию один раз на активном кадре атаки (**240 мс** после начала). Ушедший из досягаемости друид не реагирует. Простое касание без атакующего жеста не запускает попадание. Существующие ходьба, касты, меню и принятые источники не перерисованы.
