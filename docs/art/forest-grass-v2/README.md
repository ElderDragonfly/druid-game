# Трава из нижних квадратов референса

Подключены [трава](grass.png) и [трава с цветами](grass-flowers.png), напрямую вырезанные из [загруженного изображения](../0301174761c1ee7f4b2a2bee8c421ad6.jpg). Исходник содержит подпись `MEZ.PIXELA`. Цвета сохранены из JPEG без перерисовки, затемнения и перекрашивания — по уточнению пользователя. Размер каждого PNG — 432×432; точные координаты и SHA-256 источника находятся в [source.json](source.json).

Генератор выбирает обычную траву с вероятностью **97%**, вариант с цветами — **3% для каждого фрагмента**. Это вероятность выбора источника, а не доля белых пикселей: сами цветы встречаются значительно реже. Источник выбирается до подбора стыка, чтобы сравнение краёв не вытесняло цветочный вариант.

Рабочие копии имеют размер 128×128. Из случайных вырезок 96×96, с восемью поворотами/отражениями и перекрытием 24 пикселя, собирается единое поле. Из 12 кандидатов выбирается наиболее подходящий, граница проходит по похожим пикселям. Вместо сетки одинаковых плиток получаются разные сочетания травы, теней и цветов. На мир — 1032 фрагмента; пиксель подстилки — 1,25 игровой единицы. Один seed воспроизводит поле, R создаёт новое.

Параметры: [FOREST_FLOOR](../../../src/world/forestFloor.ts). Прежние варианты земли сохранены в [forest-floor-v1](../forest-floor-v1/README.md).
