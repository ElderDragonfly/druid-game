# Эскизы размера и детализации друида

Две картинки для обсуждения следующего изменения. Они сгенерированы по снимкам текущих сцен и образу рабочего друида. Код, игровые PNG, параметры размеров и поведение приложения не изменены.

## Экран выбора персонажа

[Открыть картинку](character-selection-preview.png)

<img src="character-selection-preview.png" alt="Эскиз: более крупный сидящий друид на экране выбора" width="960">

Сидящий друид заметно крупнее текущего, ориентир по размеру — персонаж в главном меню. Позу поддерживает то же бревно; крупный портрет в ячейке остаётся отдельным элементом. Детализация увеличена умеренно, с сохранением крупных пиксельных форм.

## Игровой друид

[Открыть картинку](gameplay-druid-preview.png)

<img src="gameplay-druid-preview.png" alt="Эскиз: более подробный игровой друид на поляне" width="960">

Ориентир — нынешний размер героя на поляне, с более ясными формами капюшона, лица, бороды, складок плаща и посоха. Мелкие украшения и шумная фактура не возвращаются.

## Предлагаемая сетка для следующей интеграции

«На треть больше пикселей» в этой пробе означает увеличение разрешения примерно на треть **по каждой стороне**. Это целевые параметры будущих отдельных спрайтов; эти PNG показывают эскизы целых сцен.

| Вариант | Текущая сетка | Предлагаемая сетка | Масштаб на экране |
| --- | --- | --- | --- |
| Сидящий друид | 40×56 | 54×75 | Значительно крупнее, примерно как в главном меню |
| Игровой друид | 24×30 | 32×40 | Прежний размер |

Для просмотра на компьютере выполните `git pull --ff-only` и откройте PNG в этой папке. На GitHub можно открыть картинку и скачать оригинал через «Download raw file». После обсуждения выбранный вид можно подготовить как отдельную текстуру и подключить в игру.
