# Эскизы размера и детализации друида

Две картинки, сгенерированные по снимкам сцен и образу рабочего друида. Пользователь сохранил новый игровой вариант и явно указал `character-selection-preview.png` как нужный вариант для меню. Попытки повторно перерисовать сидящего друида и вернуть более ранний маленький образ отклонены.

Теперь в меню напрямую подключён правый лагерь из этого PNG, с сохранением исходных пикселей. Персонаж внутри фрагмента не отделён от окружения; кнопки и остальные элементы интерфейса остаются самостоятельными и рабочими.

Сидящий друид заметно крупнее предыдущего, ориентир по размеру — персонаж в главном меню. Позу поддерживает то же бревно; крупный портрет в ячейке остаётся отдельным элементом. Детализация увеличена умеренно, с сохранением крупных пиксельных форм.

## Текущая интеграция

Для меню берётся область (840, 80), размером 696×864 из `character-selection-preview.png`, без генерации, уменьшения сетки или изменения цветов. Она показывается в точке (525, 50), в размере 435×540 игровых единиц. В исходном PNG есть также нарисованный интерфейс; левую часть с ним не используем, чтобы сохранить настоящие кнопки и ячейки без дублирования.

Для комнаты используется отдельный прозрачный [игровой друид](../../../src/assets/characters/druid-game-source.png): сетка 32×40, отображение 87,5×109,375 игровых единиц. Игровой вариант после уточнения меню не менялся.

Изображение, масштаб и положение лагеря задаются в данных персонажа. Точное отделение сидящей фигуры из этого эскиза ещё предстоит подготовить; текущий слой содержит и персонажа, и правую часть окружения.

Для просмотра на компьютере выполните `git pull --ff-only` и откройте PNG в этой папке. На GitHub можно открыть картинку и скачать оригинал через «Download raw file».
