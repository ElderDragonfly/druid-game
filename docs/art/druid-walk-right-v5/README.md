# Полные правые ноги под плащом

Исправляет вырезанные части ног в v4. Принятые левые позы, отражённые вправо, сохраняются: каждый ранее непрозрачный пиксель слоя ног и весь низ от y=268 совпадают с v4. Четыре фазы по 240 мс, полный цикл 960 мс; размер, коллизия, скорость, руки и посох прежние.

`completion-source.png` — отдельно дорисованные полные штанины/голени по четырём исходным позам, сетка 2×2. Её клетки совмещаются с x=40..200/y=200..306 исходных кадров через NEAREST. Новые пиксели берутся только для пустых участков бёдер и дальней ноги выше y=268; палитра привязана к принятым коричневым пикселям каждой фазы. В зоне соединения под подолом (x=95..159/y=220..238) сохраняется непрозрачный объём исходной правой позы, текстура берётся из дорисовки. Узкие вырезы маски заполняются, естественное пространство между ногами остаётся прозрачным. Оригинальные пиксели штанов/сапог накладываются поверх дорисовки без изменения.

`legs-right-complete-256x320.png` — полный слой ног, `reconstructed-material-256x320.png` — только добавленный материал. Больше не используется маленькая заплатка `hip-join` из v4. Сборка: прежний дальний посох → полные ноги → прежняя правая одежда. Верх до y=220 побитово сохранён.

Подготовка: `python scripts/complete-druid-right-legs.py` (Pillow, NumPy, SciPy). Проверяются цельность связи обеих стоп с бёдрами, отсутствие внутренних дыр в ткани и закрытие трёх конкретных просветов v4 в собранном игровом спрайте. GIF — предпросмотр. V4 сохраняется как источник и архив.
