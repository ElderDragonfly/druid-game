# Basic 04: подробная ходьба вверх

Новый отдельный вариант для оценки. **В игру пока не подключён**: W продолжает использовать прежний цикл Basic 64×80. Принятые фронтальные PNG и ходьба вниз уже подключены; см. [фронтальный набор](../druid-front-refinement-v2/README.md).

- [Ходьба вверх — GIF](walk-up-preview.gif).
- [Четыре кадра рядом — PNG](walk-up-frames-preview.png).
- [Прозрачная полоса 1024×320](walk-up-256x320.png).

Четыре полные позы нарисованы по принятому подробному Basic 04. Ракурс строго со спины: капюшон, длинный тёплый оливковый плащ, коричневые сапоги без шнуровки. Лица и переднего узла сзади не видно. Нет сумок, подвесок, растений и украшений. Ноги чередуются, свободная правая рука немного движется. Положение корпуса выравнивается по центру капюшона, а не по перемещающимся ногам. Горизонтального наклона и программного вращения нет.

Посох остаётся в анатомической левой руке — со спины она **слева на изображении**. Один отделённый рисунок руки и посоха переносится целиком, без зеркалирования, изменения длины или хвата. Подъём 0 → 6 → 12 → 6 пикселей даёт **одну опору на два шага**. В заднем ракурсе плащ перекрывает часть руки и древка.

Кадр **256×320**, опорная строка y=300. GIF показана в родном размере ×1: четыре кадра по **240 мс**, цикл **960 мс**, единая палитра 256 цветов без дизеринга. Прозрачные PNG сохраняют полные цвета, альфа 0/255. Ткань и обувь приведены к фактическим цветам Basic 04 тем же способом, что во фронтальном варианте.
