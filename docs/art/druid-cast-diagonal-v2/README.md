# Исправление вращения посоха в двух диагоналях

Подключено в игру: [вниз-вправо](cast-down-right-preview.gif) и [вверх-влево](cast-up-left-preview.gif).

В обоих ракурсах изменено направление вращения посоха. Вниз-вправо нижний конец выходит наружу вправо от корпуса, вместо движения к свободной руке. Размах уменьшен: крайний наклон теперь **45° вместо 75°**, нижний конец остаётся ниже. Вверх-влево подготовлен обратный вариант вращения с таким же ограничением наклона. В этом заднем ракурсе верх посоха естественно скрывается за корпусом в середине жеста.

Старые файлы **сохранены без изменений** для сравнения и возврата:

- [Прежний вниз-вправо](../druid-cast-right-v2/cast-down-right-preview.gif).
- [Прежний вверх-влево](../druid-cast-eight-way-v1/cast-up-left-preview.gif).

Корпус, одежда, ноги, руки, точки хвата и цвета переиспользуются из принятых слоёв. Меняется только вращение прежней ветки вокруг хвата. Другие шесть направлений не менялись. Стоящие кадры 0 и 7 совпадают с прежними; кадр **512×384**, шесть активных фаз, **670 мс**, игровой масштаб и остановка при касте сохранены.

`cast-*-512x384.png` — прозрачные игровые полосы; `cast-*-keyframes.png` — кадры рядом; `art.json` — углы и координаты хвата. Пересборка: `python scripts/prepare-druid-diagonal-casts.py` (Pillow, NumPy, SciPy). Скрипт сначала собирает прежние углы из исходных слоёв и сверяет каждый кадр с прежним PNG пиксель в пиксель, затем меняет вращение. Дополнительно проверяет наклон, связность, прозрачность и отсутствие обрезания.
