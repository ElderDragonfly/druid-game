# Живой лагерь в выборе персонажа

Три независимых эффекта в `CampAtmosphere`:

- **Костёр:** небольшое колебание языков пламени и яркости. Исходный рисунок огня сохраняется; меняются выборка пикселей и свет внутри локального участка. Камни и нижняя часть костра остаются неподвижны.
- **Вода:** движение голубых струй и светлых полос в маске русла и водопада. Лес и берег не получают водную анимацию.
- **Пять светлячков:** отдельные спрайты со своими замкнутыми траекториями и мерцанием. Периоды 9,2 / 11,7 / 13,4 / 8,1 / 10,6 секунды. Основные радиусы по x 12–20, по y 9–13 единиц; малые гармоники добавляют отклонения до 3/2 единиц. Это фиксированные огоньки исходной сцены, не случайная популяция.

`environment-reference.png` — механически собранное окружение без персонажа, в системе координат 960×540. В игре оно используется только для локальных кадров огня и воды, **не заменяет весь фон**. `firefly-clean-source.png` содержит нарисованное восстановление леса под старыми пятью огоньками; `firefly-clean-patches.png` использует лишь пять маленьких круглых участков, вне их полностью прозрачен. Благодаря этому за движущимися светлячками не остаются старые неподвижные двойники. Область очистки рисуется поверх воды, потому что один исходный огонёк находится внутри её прямоугольного кадра.

Фон, пустое бревно, сидящий Basic 04 и лежащий посох сохраняют свои слои. Эффекты находятся под панелью интерфейса и под персонажем/экипировкой. Главное меню и игра не анимируются этим модулем.

Для огня и воды при входе собираются два атласа по **24 кадра**, воспроизведение **12 кадров/с**, цикл 2 секунды, фильтр NEAREST. После подготовки обновляются только номера кадров; вычислений пикселей и загрузок текстур на каждом игровом кадре нет. Нужен обычный Phaser/Canvas, без отдельного шейдера, видео или новых зависимостей. После выхода все три временные текстуры и подписка на обновление освобождаются; повторный вход не дублирует объекты.

Координаты и скорости — `src/data/campAtmosphere.ts`; отрисовка и жизненный цикл — `src/rendering/CampAtmosphere.ts`. Локальные маски очищенных огоньков воспроизводятся через `scripts/prepare-camp-atmosphere.py`. Прежние согласованные PNG не изменены.
