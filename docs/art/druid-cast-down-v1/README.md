# Жест заклинания посохом — лицом к игроку

Пользователь явно вернулся к этой версии после проб v2/v3. Этот исходный PNG теперь подключён к атаке вниз **без изменения пикселей**. Подготовлены и подключены [семь остальных направлений](../druid-cast-eight-way-v1/README.md). Исторические v2/v3 сохранены отдельно и в игре не используются.

- [Посмотреть GIF](cast-down-preview.gif).
- [Все восемь кадров рядом](cast-down-frames-preview.png).
- [Прозрачная полоса PNG](cast-down-512x384.png).

Друид приподнимает посох левой рукой, поднимает его для жеста, проводит перед грудью и возвращается в исходную стойку. Правая рука остаётся свободной. Стопы опираются на землю; немного меняются плечи, ткань и распределение веса. Это жест для заклинания. В игре он запускается стрелками, две соседние стрелки задают диагональ; WASD остаётся независимым движением. Урон, снаряды и эффекты заклинания пока не добавлены.

Нарисованы шесть отдельных поз тела по принятому Basic 04. Ткань согласована с палитрой утверждённого [стоящего игрового друида](../druid-front-refinement-v2/idle-down-256x320.png). Один посох вырезан из этого же PNG и поворачивается как цельный предмет, без изменения длины или формы развилки. Небольшой участок стержня, скрытый исходной ладонью, соединён соседними пикселями того же дерева; его снова перекрывает новая держащая кисть. Порядок слоёв: тело → посох → пальцы и край кисти. Хват во всех позах остаётся анатомически левым.

## Параметры

- Восемь кадров: исходная стойка, шесть поз жеста, та же исходная стойка.
- Сам жест: **670 мс**. Полный цикл с паузой для просмотра: **1430 мс**.
- Длительности: **320 / 100 / 120 / 80 / 130 / 110 / 130 / 440 мс**.
- Кадр **512×384**, фигура в прежней детализации около **280 пикселей** высотой. Дополнительная ширина нужна для размаха; сам герой не увеличен. Исходная фигура 256×320 размещена со сдвигом **(128, 40)**, игровая точка опоры в этом эскизе — **(256, 340)**.
- Игровой размер, скорость и физическое тело не менялись, поскольку файлы пока не импортируются игрой.
- Прозрачные PNG имеют альфу 0/255. GIF использует общий набор из 256 цветов без дизеринга и однотонный лесной фон для просмотра.

## Исходники и повторная подготовка

- `body-source.png` — шесть нарисованных полных поз без посоха, 3×2.
- `pose-guide.png` — схема положений левой руки.
- `body-poses-512x384.png`, `staff-poses-512x384.png` — раздельные слои для шести новых поз.
- `staff-master-256x320.png` — единственный исходный слой посоха.
- `cast-down-00.png` … `cast-down-07.png` — отдельные прозрачные кадры.
- [art.json](art.json) — фазы, углы, точки хвата, длительности и привязки.

Пересборка: `python scripts/prepare-druid-cast-down.py` (Pillow, NumPy, SciPy). Проверяются размеры, восемь кадров GIF и его длительность, семь различных изображений, бинарная прозрачность, отсутствие обрезания, цельность исходного посоха и точное совпадение первой/последней позы с утверждённым PNG. Сборщик только подготавливает художественные файлы.
