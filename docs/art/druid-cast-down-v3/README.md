# Жест посохом по видеореференсу

Отдельная проба для оценки, **в игру не подключена**.

- [GIF движения](cast-down-preview.gif).
- [Восемь ключевых кадров](cast-down-keyframes.png).
- [Прозрачный лист кадров](cast-down-sheet.png).

Вторая проба не совпала с желаемым жестом. В этой версии основой служит присланное пользователем видео: первый фронтальный дубль, участок примерно **3,7–5,3 с**. Движется не только навершие: кисть сначала проходит перед корпусом, затем рука выносит посох вперёд и в сторону и возвращается к исходной стойке. Наклон ветки меняется вместе с рукой. Посох сохраняет длину; сильное перспективное укорочение из v2 убрано.

Положения кисти, локтя и наклоны древка отмечены вручную по кадрам ролика. Между отметками используется плавная интерполяция без выбросов; траектория адаптирована к пропорциям друида. При выносе руки к камере меняется видимая длина предплечья, размер кисти сохраняется. Движение из видео растянуто с 1,6 до 2,25 с, чтобы жест читался неспешно. Это художественная адаптация референса, а не автоматический захват движения.

Корпус остаётся одним слоем из v2: исходный [стоящий друид](../druid-front-refinement-v2/idle-down-256x320.png) с локально восстановленной тканью под прежней левой рукой. Масштаб, лицо, пояс, плащ и ноги по кадрам не меняются. Левая рука сгибается в локте. Для неё подготовлен отдельный рисунок вытянутой руки; из него взяты только рукав, обмотка предплечья и кисть, без нового корпуса. Древко находится перед корпусом и под пальцами в месте хвата. Другая рука свободна. Используется прежний вырезанный посох без украшений. При пересечении лица посох естественно перекрывает его, как в ролике.

## Параметры

- **61 кадр**, кадр 512×384; движущиеся фазы по 50 мс.
- Подготовка 300 мс, жест по видео 2250 мс, возврат 400 мс.
- Полное движение 2950 мс; повтор с паузами 4100 мс.
- Атлас: 6 столбцов × 11 строк, занята первая 61 ячейка.
- [art.json](art.json) хранит отметки из видео, положения кисти/локтя, наклоны и длительности.
- Сам ролик и фотографии пользователя в репозиторий не добавлены.

Пересборка: `python scripts/prepare-druid-cast-down-v3.py` (Pillow, NumPy, SciPy). Корпус и посох переиспользуются из v2; `arm-source.png` и `arm-source-normalized.png` сохраняют новый исходник руки и его подготовленную копию, а три маленьких PNG — выделенные части руки. Прежние версии сохранены. Проверяются плавность движения кисти/локтя без смены стороны сгиба, точная исходная стойка в начале и конце, бинарная прозрачность, отсутствие отдельных висящих пикселей, обрезания кадром и длительность GIF. Игровой код не менялся.
