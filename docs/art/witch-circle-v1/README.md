# Мухоморы ведьминого круга

Пользовательские референсы из коммита `953a18d`:

- `76c2b537db5e76dd2a71bbae16fe2efc.jpg` — четыре вида маленьких мухоморов, все вырезаны отдельно.
- `3aaf750541e7c159c68cc3a6dcb5b811.jpg` — по уточнению пользователя сохранена **вся композиция**: большой гриб, маленький рядом, трава у основания.

`python scripts/prepare-witch-circle.py` механически выделяет спрайты, удаляя фон снаружи и нейтральную кайму JPEG. Внутренние светлые пятна на шляпках сохраняются. RGB непрозрачных пикселей копируются из соответствующего исходника, рисунок не генерируется и не перекрашивается. `sprites.json` содержит размеры, опоры и координаты исходных фрагментов.

`ring-0.png` … `ring-3.png` — отдельные PNG; `ring-atlas.png` — игровой атлас, `central.png` — полная центральная композиция, `collection.png` — коллекция для GitHub. В игре используются NEAREST и отдельные слои с сортировкой по y, без физических тел.

Параметры `WITCH_CIRCLE`: примерная высота друида 96, диаметр кольца 144, диаметр зоны без деревьев/кустов 192, высота центра 64. **12–16** периферийных грибов всех четырёх видов, высота 12–18, разброс радиуса ±5. Подбор центра: вход в круг и удержание E 1000 мс, без изменения характеристик/HP, без награды; состояние собрано сохраняется.
