# Центральная композиция ведьминого круга

Здесь сохранён принятый `central.png`: большой мухомор, маленький рядом и трава у основания. Источник — `../3aaf750541e7c159c68cc3a6dcb5b811.jpg` из коммита `953a18d`. Размер в игре — 64 единицы по высоте, без коллизии.

`python scripts/prepare-witch-circle.py` механически удаляет фон; RGB непрозрачных пикселей сохраняются. `sprites.json` содержит координаты фрагмента, размер и опору.

Прежние четыре маленьких спрайта, их атлас и коллекция удалены по запросу пользователя. [Текущее кольцо из девяти грибов и почва](../witch-circle-v2/README.md).
