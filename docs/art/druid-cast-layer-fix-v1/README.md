# Четыре каста без наложения второй фигуры

В игру подключены [вверх](cast-up-preview.gif), [вверх-влево](cast-up-left-preview.gif), [вверх-вправо](cast-up-right-preview.gif) и [вправо](cast-right-preview.gif).

В прежней сборке неподвижный плащ копировался поверх полного нарисованного кадра тела. По краям и у подола оставались части другого корпуса, ноги и свободная рука менялись отдельно. Это создавало двойные контуры. Теперь порядок слоёв один: **движущийся посох → отдельная левая рука → единственный корпус**. Корпус естественно скрывает дальнюю руку и часть посоха; целая вторая фигура под ним отсутствует.

Основа взята из соответствующей стоящей позы. Удалены прежний посох и держащая его кисть, восстановлена только скрытая ткань. Новая генерация `body-clean-source.png` используется только для локальных участков, а не для замены героя целиком. Неподходящие участки руки из предложенного рисунка отбрасываются; ткань также переиспользуется из видимых исходных складок. Вне `body-edit-mask-*.png` исходные пиксели сохранены. Голова, свободная рука, основной рисунок плаща и ноги не заменяются отдельными движущимися версиями.

Шесть авторских фаз руки и исходная ветка сохранены. Вверх-влево сохраняет ранее выбранное обратное вращение и предел 45°. Для профиля вправо рука и посох вместе зарегистрированы на 18 пикселей ближе к плечу: прежние рисунки располагали плечо дальше вперёд относительно стоящей фигуры. Фигура и её коллайдер не сдвигаются.

Длительность **670 мс**, кадр **512×384**, поля **128×40**, масштаб и управление прежние. **Принятый каст прямо вниз не менялся**, как и вниз-влево, вниз-вправо и влево. Прежние варианты четырёх исправленных направлений сохранены в своих папках.

`body-*-fixed-256x320.png`, `arm-*-poses-512x384.png`, `staff-*-poses-512x384.png` — проверяемые слои. `cast-*-512x384.png` — игровые полосы, `cast-*-keyframes.png` — кадры рядом. Параметры хвата и углов находятся в `art.json`.

Пересборка: `python scripts/prepare-druid-layered-casts.py` (Pillow, NumPy, SciPy). Проверяются неизменность каждого непрозрачного пикселя единственного корпуса во всех фазах, отсутствие фигуры за пределами трёх слоёв, связность и отсутствие обрезания. `npm run build` и `npm test` проверяют также реальные игровые текстуры: в слое руки нет второго подола/ног, корпус не меняется, обычный игровой спрайт скрыт во время каста. Сохраняются проверки всех восьми направлений, остановки и повтора каста, возобновления ходьбы и прежних игровых сценариев.
