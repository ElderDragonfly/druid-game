# Кусты без подложек, общая лесная палитра

По следующей правке пользователя полностью убраны яркие плоские пятна земли и их обрывки под всеми восемью кустами. В игре загружается только `foliage-atlas.png`; слоя земли у кустов больше нет. Исходный JPEG и первая вырезка в `forest-bushes-v1` сохранены отдельно.

`palette-reference.png` — цветовой эскиз, отредактированный по прежней коллекции и реальной траве игры. Рабочие PNG собирает `python scripts/prepare-bushes-v2.py`: берёт прежние пиксельные рисунки, очищает нижние контуры и остатки подложек, переносит все восемь растений в **одну палитру из восьми зелёных оттенков**, сохраняя различия света и тени. Палитра записана в `sprites.json`. Новая форма листьев из эскиза в игру не подставляется.

Контуры — тёмно-зелёные, средние тона — приглушённые лесные, блики — умеренные оливковые. Кусты темнее травы и отделяются от неё контуром; прежних бирюзовых, фиолетовых и неоновых цветов нет. Непрозрачность оставшихся листьев — 255, сглаживание не используется.

`bush-0.png` … `bush-7.png` — отдельные спрайты; `collection.png` — коллекция для GitHub. Текущий игровой масштаб **7/12**: на **75% больше** прежнего 1/3. PNG и их опоры те же, масштаб задаётся в `src/data/bushes.ts`.

Все **24–36** кустов размещаются в центральной части левой средней комнаты (индекс 3), вне очищенной зоны ведьминого круга. Зазор между рисунками — 8 единиц. Кусты остаются в нижнем слое под героями. По решению пользователя **коллизии отключены**: физических прокси и оснований в навигационной геометрии нет, персонажи и снаряды проходят свободно. Прежний вариант оснований сохранён в истории коммита `0f0ca12`.
