# Диагональная ходьба: ноги в настоящем ракурсе вполоборота

Предыдущая версия сохранена для сравнения. В игре используется [обновление со стыком по подолу и спокойной задней походкой](../druid-diagonal-legs-v2/README.md). Изменена только нижняя часть четырёх диагональных анимаций: колени, голени, пятки и носки сапог теперь нарисованы в направлении движения. Прежнего скоса фронтальной/задней картинки нет. Стоящие позы и ходьба по четырём основным направлениям сохранены.

Кадр 256×320, четыре фазы по 240 мс при начальной скорости, цикл 960 мс. Размер героя в мире, скорость и темп прежние. Во фронтальных диагоналях видны передняя и боковая поверхности сапог; в задних — пятки и боковые поверхности, носки направлены от зрителя.

Принятые корпус, плечи, руки, посох, плащ и его цвет копируются из `druid-eight-way-v1`. Все пиксели выше y=225 совпадают с прежними PNG, включая прозрачные области. Ниже этой границы прежняя ткань и её край перекрывают новые ноги. Дальний посох рисуется за ногами, ближний перед ними; изменение перекрытия не подменяет его рисунок. Пять отдельных тёмных пикселей старой вырезки посоха у нижнего края в одном кадре удалены: после смены ног они висели отдельно от фигуры.

## Исходники и сборка

- `legs-down-right-source.png` — четыре нарисованные нижние части в переднем ракурсе вполоборота.
- `legs-up-right-source.png` — четыре нижние части в заднем ракурсе вполоборота.
- Для левых направлений отражается только симметричный рисунок штанов и сапог. Корпус, руки, посох и плащ не отражаются.
- `legs-{направление}-256x320.png` — слои ног в общей сетке.
- `protected-{направление}-256x320.png` — технические маски неизменяемых пикселей для проверки сохранности принятой графики.
- `walk-{направление}-256x320.png` — итоговые полосы, загружаемые игрой.

Новые ноги равномерно уменьшаются одной общей величиной для четырёх фаз с привязкой к тазу; стопы не используются для покадрового выравнивания. Деформации со скосом и повороты фронтальных ног не применяются. Цвет кожи сапог и штанов согласован с принятой коричневой палитрой; цвета плаща не пересчитываются. GIF используют одну палитру без дизеринга, игровые PNG сохраняют полные цвета и прозрачность 0/255.

Сборка: `python scripts/prepare-druid-diagonal-legs.py` (Pillow, NumPy, SciPy). Скрипт использует старый набор как неизменяемый источник, новые файлы сохраняет только в эту папку. Метаданные: [art.json](art.json).
