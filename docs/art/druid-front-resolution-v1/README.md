# Фронтальный друид: 48×60 и 64×80

Два отдельных PNG для выбора пиксельной сетки:

- [48×60](druid-front-48x60.png) — более крупные пиксельные формы.
- [64×80](druid-front-64x80.png) — больше места для деталей.

Оба получены из фронтального ракурса [одобренного листа](../druid-turnaround-v3/druid-four-views.png), без генерации нового образа. Использован тот же кадр и положение фигуры, что в игре. Меняется только разрешение: мелкие штрихи усреднены, края силуэта имеют прозрачность 0 или 255, палитра не ограничивалась. Ручная перерисовка не выполнялась.

Размеры файлов настоящие: 48×60 и 64×80 пикселей. Чтобы сравнить их в одинаковом размере без сглаживания, после `git pull --ff-only` откройте **compare.html** из этой папки в браузере. Это локальный просмотр двух PNG, без игрового приложения и сервера: первый увеличен в четыре раза, второй — в три, оба показаны как 192×240.

Для отдельного скачивания откройте PNG на GitHub и нажмите «Download raw file». Пользователь выбрал 64×80, и этот PNG подключён в игровую комнату без повторной обработки. Три остальных ракурса теперь подготовлены из того же одобренного листа и подключены в игру: [влево](../../../src/assets/characters/druid-left-64x80.png), [вправо](../../../src/assets/characters/druid-right-64x80.png), [со спины](../../../src/assets/characters/druid-back-64x80.png). Фронтальный файл не изменён. Все ракурсы имеют сетку 64×80 и общую опору ног; WASD переключает соответствующие изображения. Размер на поляне и физическое тело прежние. Версия 48×60 остаётся для сравнения.
