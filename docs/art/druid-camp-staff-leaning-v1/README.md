> Архивный, отвергнутый пользователем вариант: посох слишком вертикальный. В игре снова используется прежний `druid-basic-seated-v1/staff-lying.png`, с немного приподнятой правой развилкой на бревне.

# Посох с опорой на бревно

`staff-leaning.png` — отдельный прозрачный слой 696×864 на общей сетке лагеря. Развилка направлена вверх, древко наклонено к правому краю бревна, основание опирается на землю рядом с сидящим друидом. Фигура, обе руки на коленях и фон лагеря берутся из прежних файлов `druid-basic-seated-v1` без изменений. Посох не пересекается с фигурой и меняется через `CharacterDefinition.camp.props`.

Новая ориентация нарисована в `staff-source.png` с опорой на прежний голый коричневый посох. `scripts/prepare-camp-leaning-staff.py` выделяет связный рисунок, убирает внешнюю полупрозрачную кайму и размещает его на сетке 2 нативных пикселя с NEAREST. Границы слоя: (532,390)–(678,770); размер рисунка 146×380. `camp-preview.png` — только композиция для просмотра; в игре по-прежнему отдельные слои.

Предыдущий горизонтальный посох и его исходники сохранены в `druid-basic-seated-v1`. Ни главное меню, ни игровые спрайты не изменены.
