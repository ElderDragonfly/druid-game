# Гриб над друидом при получении награды

Источник: `../63fb1f7cb8d18a0ed6781a20e964d1c7.jpg`. Выбран только крайний правый жёлто-оранжевый гриб. `mushroom.png` — фрагмент `[933,108,1091,260]`, 158×152.

Вырезка механическая: удалён только внешний фон, все замкнутые внутренние области остаются непрозрачными. RGB оставшихся пикселей совпадает с JPEG. Нет перерисовки, перекрашивания, прореживания или удаления внутренних светлых/тёмных участков. `art.json` содержит исходник и координаты.

Подготовка: `python scripts/prepare-mushroom-pickup.py` (Pillow, NumPy, SciPy); тот же скрипт синтезирует короткий звук. В игре спрайт показывается шириной 40 единиц с NEAREST над головой около 1,1 секунды: небольшой подъём, сияние и затухание. Эффект вызывается только успешным сбором центральной композиции ведьминого круга. Лечебные грибы на брёвнах не изменены.
