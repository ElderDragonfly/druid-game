# Трава с видимой высотой — два эскиза

Оба эскиза сохранены без изменения PNG. **Вариант 2 подключён к игровой земле**, вариант 1 остаётся для сравнения. Деревья, персонаж и меню не изменены.

- [Вариант 1 — последний референс](grass-latest-reference.png): свежая светло-зелёная основа, изумрудные и сине-зелёные тени, редкие белые цветы. Основа — два нижних квадрата [последнего присланного изображения](../0301174761c1ee7f4b2a2bee8c421ad6.jpg).
- [Вариант 2 — предыдущая лесная трава](grass-previous-reference.png): приглушённые мшистые и оливковые оттенки, тёмные основания пучков. Ориентиры — [крупный фрагмент травы](../c3e467bb5f529d23e9ca1a1562128800.jpg) и [лесная сцена](../54745270c4172d0663edc548cd5a7587.jpg).

Оба изображения нарисованы заново по референсам, а не вырезаны из них. Пучки направлены вверх по экрану: видны основания и высота травинок, с ракурсом для игры с видом сверху под углом. Это цельные изображения травы вместе с подложкой, без прозрачных отдельных пучков.

Игра загружает выбранный PNG напрямую. Рабочая копия — 256×256 с фильтром NEAREST. Генератор берёт случайные вырезки 96×96 с началом в диапазоне **0–160** по каждой оси. Поворотов и отражений нет, поэтому направление травы и освещения сохраняется. Перекрытие 24 пикселя; на стык рассматриваются 12 кандидатов, граница проходит по похожим пикселям без размытия. Поле 3072×1728 содержит **1032 фрагмента**, пиксель пола занимает 1,25 игровой единицы, итоговый мир — 3840×2160. Один seed воспроизводит подстилку, R создаёт новую. Источник только один: прежняя светлая трава не подмешивается, редкие светлые детали берутся из самого выбранного рисунка. Предыдущие источники сохранены в [forest-grass-v2](../forest-grass-v2/README.md) и [forest-floor-v1](../forest-floor-v1/README.md).

Статичная трава слегка скрывает обувь друида: глубина перекрытия около **5 игровых единиц** (4 пикселя подстилки), вместо прежних 8. Для этого используется отдельная пиксельная маска `src/assets/environment/grass-coverage-heights.png`, 256×256. Чёрный пиксель обозначает грунт или просвет; ненулевое значение — расстояние травинки до её основания. PNG с рисунком поля и оба эскиза сохранены без изменений.

Маска подготовлена скриптом `scripts/prepare-grass-coverage.py` (Python 3 + Pillow, нужен только для художественной подготовки). В нём заданы 35 участков с существующими пучками и положением их оснований. Внутри участков выбираются пиксели стеблей, листьев и связанных с ними светлых кончиков по цвету и связности; изолированные блики и мелкие пятна отбрасываются. **Прямоугольники участков не закрашиваются в маску**, просветы между травинками остаются прозрачными. Готовая маска проверена визуально и отдельно загружается игрой, распознавания цветов во время движения нет. Пересоздание маски: `python scripts/prepare-grass-coverage.py`; исходные изображения скрипт не изменяет.

Генератор переносит маску теми же вырезками и неровными стыками, что цвета подстилки. Травинки с основанием перед ступнями рисуются поверх нижней части героя; если основание уже позади него, перекрытия нет. Случайные параметры поля прежние: 1032 фрагмента, 12 кандидатов на стык, без дополнительных случайных пучков. Ровный покров и просветы не скрывают обувь.

Для отрисовки используется один прозрачный слой **52×4 пикселя** с NEAREST, обновляемый при смене пиксельной позиции ступней после физического шага. Цвета берутся из готовой подстилки. Дополнительно в памяти остаются RGBA поля и маска высот (около 25,3 МиБ суммарно); отдельные физические тела и тысячи объектов травы не создаются. При выходе из поляны или её смене маленькая текстура освобождается. Покачивание и приминание не добавлены.
