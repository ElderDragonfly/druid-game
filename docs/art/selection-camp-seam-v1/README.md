# Единое окружение выбора персонажа

У прежнего окружения был вертикальный стык x=525: правая прямоугольная подложка отличалась от левой части. Здесь фон собран одним изображением 960×540 без персонажа и экипировки. Basic 04, посох и атмосферные эффекты по-прежнему отдельные слои.

`repair-source.png` — художественное восстановление стыка. `scripts/prepare-camp-seam.py` использует только столбцы 503–553, с плавным переходом к исходному окружению. Вне полосы и старого нижнего футера исходные пиксели сохраняются точно. С y=528 показана прежняя земля вместо плоской полосы предпросмотра.

`water-reference.png` и `water-frames.png` используют исправленную подложку и все прежние дельты анимации из `selection-water-flow-v2`, чтобы локальный прямоугольник воды не возвращал старый шов. Маски, русло, 144 кадра и 24 FPS прежние. Пламя и светлячки не переделывались.

Подготовка: `python scripts/prepare-camp-seam.py` (Pillow, NumPy). Игра переключает готовые кадры; изображения не пересчитываются во время игры.

Горизонтальный стык над костром тоже исправлен: прежняя подложка удаления пламени вписана в фон с переходом по внешнему контуру в 12 пикселей. Камни/угли с local y=125 сохранены точно. `fire-clean-mask.png` хранит веса перехода, `fire-base.png`/`fire-reference.png` — соответствующий участок фона. `fire-frames.png` содержит те же 37 принятых слоёв пламени поверх него; позиция, масштаб и 18,75 FPS прежние. Вода пересобрана на согласованном фоне с прежними дельтами.

При отрисовке используются **только прозрачные эффекты**: принятый `../selection-camp-uploaded-flame-v1/flame-only-frames.png` и новый `water-overlay-frames.png`. Огонь не содержит фонового прямоугольника; вода прозрачна вне маски течения. У каждого кадра два внешних пикселя полностью прозрачны. Полные `fire-frames.png`/`water-frames.png` остаются эталонами композиции для проверок, в сцене они не рисуются. Это устраняет границы накладок в WebGL при дробном масштабировании. Движения/скорости эффектов прежние.

`npm run test:camp-render` проверяет реальные пиксели WebGL на границах эффектов при трёх размерах окна; обычные проверки сравнивают композицию прозрачных кадров с эталонами 1:1.
