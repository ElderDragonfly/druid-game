# Единое окружение выбора персонажа

У прежнего окружения был вертикальный стык x=525: правая прямоугольная подложка отличалась от левой части. Здесь фон собран одним изображением 960×540 без персонажа и экипировки. Basic 04, посох и атмосферные эффекты по-прежнему отдельные слои.

`repair-source.png` — художественное восстановление стыка. `scripts/prepare-camp-seam.py` использует только столбцы 503–553, с плавным переходом к исходному окружению. Вне полосы и старого нижнего футера исходные пиксели сохраняются точно. С y=528 показана прежняя земля вместо плоской полосы предпросмотра.

`water-reference.png` и `water-frames.png` используют исправленную подложку и все прежние дельты анимации из `selection-water-flow-v2`, чтобы локальный прямоугольник воды не возвращал старый шов. Маски, русло, 144 кадра и 24 FPS прежние. Пламя и светлячки не переделывались.

Подготовка: `python scripts/prepare-camp-seam.py` (Pillow, NumPy). Игра переключает готовые кадры; изображения не пересчитываются во время игры.
