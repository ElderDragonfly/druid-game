# Контур каста вниз-влево и цвет посоха влево

Подключены три файла: `cast-down-left-512x384.png`, `idle-left-256x320.png`, `walk-left-256x320.png`. Прежние PNG/GIF остались в исходных папках для возврата. Принятый каст **прямо вниз** не изменялся.

## Каст вниз-влево

В предыдущей неподвижной основе восстановленная ткань добавляла **40 непрозрачных пикселей** за пределами силуэта стойки, между y=152 и y=168. Теперь фон за исходным контуром остаётся прозрачным. Из движущейся руки также убраны внешние зелёные фрагменты прежнего широкого плаща; оттенки внутри самого рукава сохраняются.

Рука, точки хвата, углы и прежний посох переиспользованы. Корпус, ноги, масштаб и длительность **670 мс** прежние. [GIF](cast-down-left-preview.gif) и [кадры рядом](cast-down-left-keyframes.png). Неподвижная основа и выделенные руки сохранены отдельно для проверки.

## Посох влево

Тёплое дерево в стойке и ходьбе влево было заметно желтее основного посоха. RGB древесины перенесены из `../druid-cast-down-v1/staff-master-256x320.png` одной общей таблицей оттенков для стойки и четырёх кадров ходьбы. Сохраняются рисунок развилки, положение, фактура и вся прозрачность. Вне `*-wood-mask.png` каждый пиксель совпадает с прежним PNG: лицо, рука, одежда, ноги и сапоги не перекрашиваются.

Пересборка: `python scripts/prepare-druid-facing-fixes.py` (Pillow, NumPy, SciPy). Скрипт проверяет границы неподвижной фигуры, неизменность ног, прозрачности и пикселей вне масок цвета, связность и отсутствие обрезания. `npm run build` и `npm test` проверяют загрузку выбранных PNG, границы корпуса и цвет древесины в реальных текстурах игры, вместе с прежними сценариями движения и каста.
