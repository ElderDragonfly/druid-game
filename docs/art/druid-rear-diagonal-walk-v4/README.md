## Исправления

**Шаг.** Прежние задние рисунки в основном поднимали сапоги, почти не меняя ведущую ногу. Теперь нарисованы четыре позы целой ноги от бедра: передняя опора, отведение опорной ноги, задняя опора, перенос с согнутым коленом. Две ноги используют этот общий цикл со сдвигом на два кадра и отдельными точками крепления к тазу. На двух контактных фазах ведущая стопа действительно меняется: ближний сапог сначала позади дальнего, затем впереди него. Движение происходит в обеих координатах проекции, а не только вверх-вниз.

Рисунки изначально имеют задний ракурс вполоборота; фронтальные ноги не скашиваются. При сборке рисунки регистрируются по бедру и подошве, общий поперечный масштаб сохраняет объём икр и сапог. Дальний слой рисуется за ближним. Отражаются только ноги для левого направления; руки и посох не меняют анатомическую сторону. Слой ног уходит под принятый контур плаща с контактной тенью. Тёмная коричневая палитра берётся из прежнего утверждённого стоящего PNG тем же постоянным цветовым преобразованием, что в v3.

**Полоса на плечах.** Старый сборщик копировал голову первой позы прямоугольником до y=97 во все остальные позы. В третьем кадре вверх-вправо получался заметный горизонтальный стык с другими плечами. Восстановлены цельные исходные рисунки капюшона и плеч каждого кадра до y=140. Их палитра восстановлена по соответствиям RGB из принятого изображения; посох собран отдельным слоем в прежнем порядке. Верхняя ткань больше не обрезается по линии головы. Ниже сохраняются принятые корпус, руки и контур плаща.

## Размеры и подготовка

- Кадр **256×320**, полоса **1024×320**, прозрачность 0/255, NEAREST.
- **4 × 240 мс = 960 мс** при начальной скорости; по 480 мс на каждую половину шага. Скорость, физическое тело, положение опоры и переключение стоящих поз не менялись.
- `single-leg-source.png` — четыре нарисованные позы одной целой ноги; [pose-guide.png](pose-guide.png) — схема постановки.
- `near-leg-*.png`, `far-leg-*.png` — проверяемые раздельные слои; `legs-*.png` — их сборка.
- `protected-*.png` — маски пикселей, точно сохранённых из предыдущего корпуса; область восстановленных плеч до y=140 исключена. `garment-*.png` — контур перекрывающей одежды.
- `walk-*.png` — игровые полосы; `walk-*-preview.gif` — просмотр на GitHub.
- [art.json](art.json) — точки постановки, порядок фаз и исходники.

Пересборка: `python scripts/prepare-druid-rear-diagonals-v4.py` (Pillow, NumPy, SciPy). Исходники прежних версий сохранены. Браузерные проверки проверяют смену ведущей стопы, перенос обеих ног, точные исходные коричневые RGB, устранение горизонтальной полосы, загрузку игровых кадров 1:1, порядок анимации и остановку.
