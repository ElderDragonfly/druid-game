# Пень для начала обряда

Исходник — загруженный пользователем [JPEG](../f5420a528a7b5430d756f6ade291bd90.jpg). Из него механически удалены нейтральные белый фон и серая подложка; оставлена связная фигура пня с прикреплёнными растениями и грибами. Исходные непрозрачные RGB не перекрашиваются. Грибы на этом рисунке декоративные, отдельно не собираются.

`stump.png` имеет прозрачный фон и защитные 2 пикселя по краям; `sprite.json` содержит SHA-256 исходника, координаты вырезки, размер и опору. Подготовка: `python scripts/prepare-ritual-stump.py` (Pillow, NumPy, SciPy). В игре масштаб 0,25 с NEAREST: примерно 113×107 игровых единиц.

Свечение и кольцо рисуются отдельными слоями в `StumpRitual`, исходная картинка от активации не меняется. Это визуальный прототип обряда; набег и проклятие врагов пока не подключены.
