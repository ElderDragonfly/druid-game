# Поочерёдный шаг вправо

Активная правая походка — восемь кадров 256×320. Полный цикл по-прежнему 960 мс при базовой скорости, 120 мс на кадр; прежние четыре положения корпуса дублируются попарно. Стоящий правый ракурс и остальные направления не менялись.

Нижняя часть собрана заново из отдельно нарисованной ноги `leg-master.png`, без старых ног и статичной подложки. У каждой ноги собственная непрерывная траектория от бедра через колено до сапога. Циклы сдвинуты на полпериода: одна нога проходит назад в опоре, другая переносится вперёд, затем они меняются. Общий центр траекторий стоп исключает постоянно ведущую ногу. Размах — 36 native-пикселей, подъём стопы — до 5 пикселей. Дальняя нога перекрывается ближней даже при смене ведущей стопы.

Цвета брюк и сапог взяты из принятых правых спрайтов; координаты верхней части, рука, посох и движение корпуса берутся из `druid-eight-way-v1` без изменений выше y=220. Порядок: дальний посох → дальняя нога → ближняя нога → прежняя одежда. Слой одежды не содержит сапог ниже y=268. Нет подложки старой голени, смешивания прозрачных кадров или отражённого посоха.

Подготовка: `python scripts/prepare-druid-right-walk-v3.py` (Pillow, NumPy, SciPy). Две отдельные полосы ног и `garments-256x320.png` сохранены для проверки состава кадра. `art.json` записывает положение бедра/стопы и фазу опоры для обеих ног во всех кадрах. Игра загружает итоговую PNG-полосу 1:1 с NEAREST; GIF служит просмотром.
