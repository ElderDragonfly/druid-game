# Грибы без светлой каймы

Те же семь спрайтов и прежние размеры/масштаб. В двух фиолетовых шляпках убрана светлая бежевая JPEG-кайма, оставшаяся после первой вырезки: `mushroom-2` — 63 пикселя, `mushroom-4` — 211.

Меняется только alpha бледных пикселей во внешнем трёхпиксельном контуре шляпки, связанном с наружным фоном. Ножки ниже шляпки и внутренние светлые детали не затрагиваются. RGB всех оставшихся пикселей сохранены, остальные пять изображений идентичны прежним. Исходные PNG остаются в `../fallen-logs-v1/`.

`mushroom-N-removed.png` — маски удалённой каймы для проверки; `sprites.json` хранит прежние параметры, исходные/новые количества пикселей и отчёт. Игра загружает отдельные PNG с NEAREST. Сборка: `python scripts/prepare-log-mushroom-edges.py` (Pillow, NumPy, SciPy), без генерации нового рисунка.
