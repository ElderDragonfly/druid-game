# Друид: неподвижная поза и ходьба вниз

Отдельное предложение для оценки. **К игре не подключено**; игровые спрайты, другие направления и меню сохранены.

- [Стоящий лицом к игроку — PNG ×4](idle-down-preview.png).
- [Ходьба вниз — GIF ×4](walk-down-preview.gif).
- [Все четыре кадра ходьбы — PNG ×4](walk-down-frames-preview.png).
- Прозрачные файлы: [неподвижный спрайт 64×80](idle-down-64x80.png), [полоса ходьбы 256×80](walk-down-64x80.png).

За основу взят утверждённый [Basic 04](../druid-sprites-v1/druid-04-basic.png): капюшон, седая борода, верёвочный пояс, посох без украшений, сапоги без шнуровки. В неподвижной позе обе ноги стоят на земле, плащ свободно свисает вниз. В ходьбе сохранена схема прежнего принятого движения вниз: смена опорной ноги, работа таза, плеч и свободной руки. Плащ удлинён, посох опущен ближе к земле. Все четыре позы перерисованы целиком; ноги или голова между ними не переставляются программно.

Тёплая палитра тканей и сапог перенесена из Basic одним общим преобразованием для неподвижной позы и всех кадров, чтобы одинаковые исходные цвета получали одинаковый результат. Геометрия при цветокоррекции не меняется. Три небольших замкнутых просвета у нижнего края плаща устранены; естественный промежуток между ногами и отверстие около хвата посоха сохраняют прозрачность.

Сетка по-прежнему **64×80**, опора ног — y=75. Подробность меняется рисунком складок и силуэтом, разрешение не увеличивалось. GIF: четыре кадра по **240 мс**, цикл **960 мс**, увеличение ближайшим соседом ×4. Фон предпросмотра однотонный, чтобы были заметны просветы. Прозрачные PNG имеют альфа-канал 0/255; ограничение 256 цветов применяется только при кодировании GIF.

Исходники: [неподвижная фигура](front-source.png), [четыре позы ходьбы](walk-down-source.png). Они созданы редактором изображений по Basic и принятому циклу вниз. `python scripts/prepare-druid-front-refinement.py` механически отделяет полные фигуры, выравнивает их, уменьшает, согласует палитру и собирает PNG/GIF. Метаданные: [art.json](art.json). Ни скрипт, ни новые изображения не импортируются игровыми сценами.

Проверены четыре разных кадра GIF, длительности, непрозрачность ткани, прозрачные поля, опора ног, отсутствие отдельных фоновых фрагментов и воспроизводимость подготовки. После художественной оценки можно отдельно согласовать подключение; правки влево, вправо и вверх остаются следующим этапом.
