# Спящий медведь

Отдельное превью для оценки; теперь его кадры используются в игре.

- [Сон с дыханием — GIF](bear-sleep-preview.gif): 4 фазы, спокойный цикл 3,6 секунды, 384×320 для просмотра.
- [Неподвижная поза — PNG](sleeping.png): прозрачная ячейка 96×80.
- `sleep-00.png` … `sleep-02.png` — три фазы дыхания, `sleep-sheet.png` — последовательность 0→1→2→1.
- [Фазы рядом](sleep-frames.png), размеры и время — `animation.json`.

Это тот же мшистый бурый медведь: тёплая охристая шерсть, зелень на спине и лбу, светлый грибок у головы. Лежит в исходном ракурсе влево вполоборота, глаза закрыты, голова опирается на передние лапы, задние лапы подогнуты.

Лежачие позы дорисованы по исходному рисунку `../7f3bc9083f8614b16f7bdff957d5eb17.jpg` и подготовленному циклу ходьбы. Новый лист `sleep-source.png` сохранён отдельно, исходники не изменены. `python scripts/prepare-bear-sleep.py` механически нарезает и выравнивает кадры по носу/линии опоры, уменьшает их NEAREST и собирает дыхание с общей палитрой. Средняя фаза повторяется на выдохе для спокойного замыкания цикла. Сохранены прозрачные поля, проверены длительности, размеры и повтор GIF.

Будущий сценарий со слов пользователя: персонаж входит, медведь просыпается, идёт ему навстречу, затем бежит. Сценарий теперь подключён: условие приближения, короткий подъём, ходьба, бег и атаки; подъём собран из существующих поз.
