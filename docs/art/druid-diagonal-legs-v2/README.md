# Диагональные ноги: цельный стык и спокойная задняя походка

Активная версия четырёх диагональных циклов. Разворот ног вполоборота сохранён. Штаны, икры и сапоги перерисованы полнее. Передние ноги теперь заходят под фактический подол туники: прежнего горизонтального обрезания на y=225 нет. На новых ногах под краем одежды добавлена небольшая контактная тень.

Во всех направлениях прежний полный цикл **960 мс** при начальной скорости. Вверх добавлены промежуточные нарисованные позы; порядок переходов согласован между опорой и переносом стопы, две противоположные опорные позы разделены половиной цикла. Нижняя точка ног в восьми задних рисунках находится на строках **297–300**: высокий отрыв обеих стоп устранён. Таз привязан к одному месту, стопы не используются для покадрового сдвига всего героя.

Принятые корпус, плечи, руки, посох и цвет одежды копируются из `druid-eight-way-v1`. Их рисунки и частота движений прежние: каждый из четырёх задних кадров корпуса показан в двух последовательных фазах ног. Все пиксели выше y=195 сохраняются точно; ниже сохраняется одежда по маске её реального контура. Для задней одежды сохранён прежний полный контур плаща. Дальний посох находится за новыми ногами, ближний перед ними. Стоящие позы и четыре основных направления не менялись.

## Сборка

- `legs-down-right-source.png` — четыре новые более полные передние позы.
- `legs-up-right-source.png` — восемь новых задних поз.
- Только симметричные штаны и обувь отражаются для левых ракурсов; корпус и посох сохраняют анатомическую сторону.
- `legs-*.png` — слои ног; `protected-*.png` — проверочные маски неизменяемых пикселей; `garment-*.png` — контуры перекрывающей одежды.
- `walk-*-256x320.png` — игровые полосы 1024×320 спереди и 2048×320 сзади. Каждый кадр 256×320, прозрачность 0/255, фильтр NEAREST.

`python scripts/prepare-druid-diagonal-legs-v2.py` (Pillow, NumPy, SciPy). Используется одна общая величина уменьшения для всего цикла, без скоса ног. Коричневая палитра согласована с принятыми сапогами; плащ не перекрашивается. GIF используют прежнюю принятую палитру. Прежние PNG остаются в соседних папках. [Метаданные](art.json) содержат количество кадров, длительности и привязки к фазам корпуса.
