# Лесное насекомое

Анимированный источник — `docs/art/dragonfly_animation_reel_3x.gif`, пользовательский коммит `2844972`. GIF содержит 80 кадров по 40 мс: парение, полёт и повторяющийся боковой удар хвостом. Предыдущий `f159b42a86f6f839184bbd2fa8c13227.jpg` — только неподвижный референс.

- `idle`, `walk`, `run` — исходные кадры 0–15, 16–31, 32–47.
- `attack-right` — кадры 48–63, `attack-left` — их точное горизонтальное отражение.
- `directional-source.png` — дорисованные ракурсы вверх/вниз: нейтральная поза, замах, удар, возврат. `attack-up/down` приведены к общей сетке и палитре GIF. Это новые рисунки, которых в исходной GIF нет.
- `shadow.png` — исходная тень отдельным слоем; фон GIF удалён по точным цветам.
- `death` — подготовленное из исходной фигуры шестикадровое падение с поворотом. В GIF самостоятельной смерти нет; это адаптация, а не извлечённая готовая анимация. Последний кадр остаётся в мире.

Все листы имеют одинаковую ячейку 128×112 и опору 64×88. Уменьшение исходного увеличенного рисунка выполняется без интерполяции, PNG с дискретной прозрачностью, в игре NEAREST. Превью GIF предназначены для просмотра на GitHub; игра проигрывает PNG-кадры. В полёте темп следует за пройденной дистанцией, при парении крылья продолжают двигаться; время удара следует за боевым профилем.

Воспроизводимая подготовка: `python scripts/prepare-room-art.py` (Pillow, NumPy). Характеристики, ИИ, коллизия и визуализация разделены; время/овалы поведения пока общие с волком, HP/скорости/урон отдельные в `entities.json`.

Вертикальные атаки дополнены взмахами крыльев. Четыре прежние позы сохранены в `attack-up-base.png` и `attack-down-base.png`; `animate-insect-attack-wings.py` выделяет внешние крылья, вращает их без сглаживания вокруг основания и накладывает исходный корпус поверх. Каждая поза получает восемь подкадров: 32 кадра за прежние 660 мс. Центральный корпус и фазы хвоста сохраняются. Скрипт вызывается общей подготовкой, повторные запуски используют сохранённые базы. Боковые атаки и полёт не перерисованы.
