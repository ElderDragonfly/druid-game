# Овальное кольцо: девять грибов и почва

Пользователь выбрал все девять видов нового листа. Источники:

- `../35e7cd8c994abfc4a9704b78fa6e2806 (1).jpg` — девять грибов;
- `../cf03e46bc0010f66ba0ccf8133753cd9.jpg` — текстура почвы; используется коричневый участок `[28,184,405,432]`, без верхней зелёной полосы.

Подготовка: `python scripts/prepare-witch-circle-v2.py`. Скрипт вырезает грибы, сохраняя RGB непрозрачных пикселей и внутренние светлые пятна. `mushroom-0.png` … `mushroom-8.png` — отдельные спрайты, `ring-atlas.png` — атлас с ячейками 128×128. `soil.png` — исходный фрагмент земли без перекрашивания. `sprites.json` содержит источники, координаты и опоры, `collection.png` — обзор для GitHub. Центральная композиция из `witch-circle-v1` не менялась.

В игре кольцо **144×96**, свободная зона **192×128**, **12–16** грибов высотой **12–18**, обязательно всех девяти видов. Углы и радиусы слегка варьируются. Почва рисуется отдельной неровной овальной маской с мягким краем: грибы не привязаны к её границе. Текстура почвы сэмплируется один раз, без мозаичного повторения; сглаживание спрайтов выключено. Только переход края почвы смешивается с прежней травой.

Кусты и кроны исключены из свободной зоны. Деревья комнаты 3 распределены вдоль краёв с минимальным расстоянием 120 между стволами; общее количество сохраняется. Старые сохранения переходят на расстановку `version: 2`, не восстанавливая уже собранный центральный гриб.
