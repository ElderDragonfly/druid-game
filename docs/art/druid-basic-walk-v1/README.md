# Basic 04 — ходьба для просмотра

Образ основан на утверждённом [Druid 04 Basic](../druid-sprites-v1/druid-04-basic.png): верёвочный пояс, голая кривая ветка-посох, без растений, медальона и подвесок. Подробный PNG Basic подключён только к маленькой доступной карточке «Друид» на экране выбора. Фон лагеря и сидящая фигура сохранены.

## Как сохраняется рисунок и движение

Верх и низ используют прежние принятые полосы. Из нового [листа локальных исправлений](front-back-edits-source.png) взяты только области пояса и верхушки посоха. Вне прямоугольников `localPatches` в [animations.json](animations.json) исходные пиксели сначала копируются без изменения. Затем программно согласуется палитра зелёной ткани и коричневых ног с Basic; положение ног, рук, головы и рисунок движения вне областей исправлений сохраняются. Со спины пояс закрыт плащом и поверх него не дорисовывается.

Боковые позы нарисованы заново по схемам короткого шага: контакт → проходящая нога → противоположный контакт → проходящая нога. Отдельно согласована светотень ближней и дальней ноги, чтобы смена опоры читалась. Для правого направления скорректирован порядок фаз и взята нарисованная фаза свободной руки с противоположным махом. Исходные листы: [влево](left-source.png), [вправо](right-source.png). PNG после подготовки включает эти исправления; он не является простым уменьшением исходного листа.

У боковых направлений **рука с посохом вынесена в отдельный слой**. В каждом направлении используется одна исходная форма, которая целиком поворачивается на 0/±4° и смещается по вертикали на 0–2 пикселя. Посох не укорачивается при переносе, хват не перерисовывается на каждой фазе. На растровой сетке контур при повороте меняется из-за округления пикселей. Положение посоха перед ногами при виде влево и за телом при виде вправо сохранено. Слева край плаща дополнительно перекрывает начало рукава.

Слои левого направления: [тело](walk-left-body-64x80.png), [рука и посох](walk-left-arm-staff-64x80.png), [край плаща поверх плеча](walk-left-cloak-foreground-64x80.png). Порядок сборки именно такой.

Слои правого направления: [рука и посох](walk-right-arm-staff-64x80.png), затем [тело](walk-right-body-64x80.png).

Это начало подготовки сменных частей, а не готовая система экипировки: пояс пока входит в рисунок тела. Сам подробный Basic, прежние GIF и используемые игрой полосы сохранены без изменений.

## Повторная подготовка

`python scripts/prepare-basic-druid-walk.py` (Python 3 + Pillow, NumPy, SciPy). Использует сохранённые листы и существующие игровые полосы. Результат воспроизводим: повторный запуск не усиливает цветокоррекцию. Скрипт очищает отделённые фоновые артефакты новых рисунков, нормализует сетку, собирает локальные исправления, переносит палитру и формирует GIF. Для прозрачных пикселей выходных PNG RGB обнулён.

Проверены четыре уникальных кадра каждого GIF, длительности, прозрачность, границы фигур и точная пересборка боковых PNG из слоёв. В верхнем и нижнем направлениях альфа-канал вне областей локальных исправлений совпадает с принятым движением. Карточка проверена в браузере: использует исходные пиксели утверждённого Basic, помещается в прежний размер 94 по высоте. Сборка и 206 проверок игры прошли.
