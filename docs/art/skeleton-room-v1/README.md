# Зелёный скелет и кости

Исходники пользователя: `../f60208be679177cf429000b0cdd76103.gif` и `../a8513c12928f616c41a84655e98e2aa5.jpg`.

`python scripts/prepare-skeleton-room.py` повторяет механическую нарезку. Удалён только внешний фон, замкнутые внутренние участки сохранены. Цвет непрозрачных пикселей не изменён, новые изображения не генерировались.

- GIF 749×286 содержит три фигуры: слева стояние, в центре удар, справа движение. Каждая повторяется через 16 кадров. Для стояния/движения взяты кадры 1–16, для удара 11–26: от подготовки до завершения одного взмаха. Начальная задержка GIF в игровые циклы не попадает.
- PNG-листы: ячейки 256×288, исходная опора `(125,248)`, игровой масштаб 0,5. Один и тот же исходный ракурс отражается для левого направления. Темп движения связан с пройденной дистанцией.
- Девять отдельных `bones-N.png` — крупные и мелкие скопления, черепа и одиночные кости. Пиксели соседнего объекта исключены выбором основной связной фигуры; замкнутые области внутри не вырезаются. `bones.json` хранит точные рамки исходных фрагментов. Игровой масштаб 0,32, без коллизии.
- GIF-превью и первые кадры — для просмотра исходных циклов. Игровая атака проигрывает один цикл за 900 мс, смерть пока обозначена коротким исчезновением, поскольку её нет в референсе.
