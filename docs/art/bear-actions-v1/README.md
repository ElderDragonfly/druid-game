# Медведь — бег и три атаки влево

Отдельные GIF для просмотра; теперь все три атаки и бег подключены в игру в обе стороны.

| GIF | Движение | Длительность цикла превью |
| --- | --- | --- |
| [Бег](bear-run-preview.gif) | Новый тяжёлый беговой цикл: толчок задними лапами, перенос передних, короткая фаза без опоры | 800 мс |
| [Удар лапой](bear-swipe-preview.gif) | Замах ближней передней лапой, вынос вперёд, возврат | 1300 мс |
| [Укус](bear-bite-preview.gif) | Подготовка, короткий выпад головой с раскрытой пастью, возврат | 1300 мс |
| [Две лапы сверху](bear-slam-preview.gif) | Подъём передней части тела, обе лапы вверх, тяжёлый удар вниз, восстановление | 1620 мс |

Каждый цикл — 8 кадров, ракурс влево вполоборота, как в исходном рисунке. У атак первый и последний кадры совпадают для спокойного возврата в стойку; перед следующей атакой в GIF есть короткая пауза. Это время **превью**, не утверждённые параметры боя или урона.

Образ — пользовательский `../7f3bc9083f8614b16f7bdff957d5eb17.jpg` и ранее подготовленная ходьба: массивный бурый медведь, охристая шерсть, мох и светлый грибок у лба. Для бега дополнительно использована схема `../abd1f9552d1a3b5fd43d3a521295b800.jpg`. Новые фазы дорисованы по референсам; это не нарезка готовой анимации из пользовательского файла. Все прежние рисунки, сон и оба направления ходьбы сохранены.

Для каждого движения сохранены:

- `*-source.png` — полный новый дорисованный лист;
- `*-00.png` … `*-07.png` — прозрачные PNG 128×96 с одинаковым полем под замахи;
- `*-sheet.png` — горизонтальный атлас;
- `*-frames.png` — фазы рядом для просмотра;
- `*-animation.json` и общий `animations.json` — размеры, длительности, регистрация и положение контакта в рисунке.

Подготовка: `python scripts/prepare-bear-actions.py` (Pillow, NumPy). Скрипт выделяет цельную фигуру по связности, чтобы выступающая за условную ячейку лапа не обрезалась и не попадала в соседний кадр. Масштаб внутри каждого движения постоянный, NEAREST; бег выравнивается по корпусу и общей линии пола ряда, сохраняя фазу полёта, атаки — по задней опорной лапе. Части тела скрипт не дорисовывает, не поворачивает и не отражает. У атак конечная стойка берётся из первого кадра. GIF использует общую палитру для всего цикла. Проверяются границы рисунка, количество фаз, длительности и повтор.
