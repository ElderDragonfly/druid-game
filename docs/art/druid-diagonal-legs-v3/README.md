# Диагональная ходьба: равномерные шаги и исходный цвет ног

Передние диагонали подключены в игру; задние обновлены в [v4: настоящий шаг и цельные плечи](../druid-rear-diagonal-walk-v4/README.md). Передние диагональные движения из v2 сохранены: те же позы, силуэты и порядок кадров. Во всех четырёх диагоналях штаны и сапоги приведены к тёмной коричневой палитре утверждённого [стоящего друида](../druid-front-refinement-v2/idle-down-256x320.png).

В предыдущем заднем цикле задержки кадров были одинаковыми, но рисунки повторяли перенос одной ноги дольше, чем другой. Сортировка по сходству соседних изображений этого не исправляла. Теперь используются четыре согласованные ключевые фазы: контакт, перенос ближней ноги, противоположный контакт, перенос дальней ноги. На каждую половину цикла приходится **480 мс**; кадр — **240 мс**, полный цикл — прежние **960 мс** при стартовой скорости. При изменении скорости темп по-прежнему меняется вместе с ней.

Для нового заднего низа нарисованы две отдельные последовательности с противоположной опорной ногой. Из каждой взяты согласованные контактная и проходящая позы: `half-a:0, half-a:1, half-b:0, half-b:1`. Остальные исходные позы оставлены в PNG, но не растягивают опору одной ноги в игре. Таз зарегистрирован в одной точке; масштаб постоянен внутри каждой исходной последовательности, высота и ширина таза согласованы между ними. Для левых направлений отражается только симметричный слой ног.

Перенос цвета использует распределение тонов настоящих штанов и сапог стоящего PNG, затем выбирает его точные RGB. Прежний поиск ближайшего RGB оставлял почти весь рисунок в самых светлых оттенках образца. Теперь одна таблица соответствия на исходный набор применяется ко всем его фазам, поэтому оттенок не меняется от кадра к кадру. Цвета берутся только из участков ног: туника, плащ, кожа и дерево не входят в образец. Контактная тень под подолом сохраняется.

Корпус, плащ, руки и посох копируются из принятого `druid-eight-way-v1`. Спереди сохранён стык по настоящему контуру туники; сзади — прежний контур плаща. Все стоящие позы, четыре основных направления, размер, скорость и окружение прежние. Старые версии сохранены в соседних папках.

## Файлы и подготовка

- `legs-up-right-half-{a,b}-source.png` — полные новые исходные рисунки задних половин шага.
- `legs-*-256x320.png` — четыре отдельных слоя ног в полосе.
- `walk-*-256x320.png` — игровые полосы **1024×320**, кадр **256×320**, прозрачность 0/255, NEAREST.
- `protected-*.png`, `garment-*.png` — маски сохранённых пикселей и одежды.
- [art.json](art.json) — фазы, длительности и источники.

Пересборка: `python scripts/prepare-druid-diagonal-legs-v3.py` (Pillow, NumPy, SciPy). Проверки браузера сверяют исходные RGB, сохранность передних силуэтов, попеременный перенос обеих стоп, опору, темп, загрузку PNG 1:1 и остановки.
