# Ходьба друида влево, вправо и вверх

Циклы для просмотра и выбора, **пока без подключения к игре**. Боковые варианты перерисованы после замечания о дёрганом движении и нечитаемой смене ног: теперь в каждом **восемь кадров вместо четырёх**. Цикл вверх и все три его файла оставлены без изменений. Образ опирается на принятую [ходьбу вниз](../druid-walk-down-v2/README.md) и [четыре стоящих ракурса](../druid-turnaround-v3/druid-four-views.png).

Новые боковые исходники — 1536×1024, по четыре фигуры в двух рядах. Исходник вида со спины — прежний 1254×1254, два ряда по две фигуры. Порядок чтения везде — слева направо, сверху вниз. Исходные рисунки сохранены непосредственно из генерации. На игровых полосах кадры 64×80 идут слева направо: восемь для каждой стороны и четыре для верха. Отклонённые боковые изображения заменены по прежним путям; отдельного архива не создавалось.

Художественное задание сохраняет посох в анатомически левой руке: в левом боковом виде это ближняя рука, в правом — дальняя, со спины — слева для зрителя. Правый цикл нарисован отдельно, а не получен зеркальным отражением левого. Для боковых циклов задана последовательность: контакт правой ногой → принятие веса → проход левой ноги под тазом с поднятой стопой → вынос левой ноги вперёд → контакт левой ногой → принятие веса → проход правой ноги → вынос правой ноги. Плащ должен оставлять читаемыми бёдра, колени и сапоги; плечи, руки и посох двигаются умеренно. Все позы перерисованы целиком. Убедительность шага оценивается по исходникам и GIF перед интеграцией.

Для всех шестнадцати новых боковых кадров использован общий масштаб **2/13**, подходящий к новому размеру исходных фигур. Чтобы не добавлять горизонтального дрожания при нарезке, середина зелёной области капюшона совмещена с x=32; нижняя граница силуэта — с y=75. Перемещается и уменьшается целая фигура, без неподвижной накладки на корпус, перестановки частей тела, зеркальных копий или растяжения отдельных частей. Непрозрачные пиксели заканчиваются на строке 74. Все фигуры помещаются без обрезания. Альфа PNG — 0 или 255; палитра игровых PNG не ограничена. Подготовленная ранее ходьба вверх не пересчитывалась.

Отдельные GIF имеют размер **192×240**, общий — **576×240**. Для сторон: **80 мс на кадр**, восемь кадров. Для верха: **160 мс на кадр**, четыре кадра. Длительность всех циклов осталась **640 мс**, бесконечное повторение. В общем GIF каждый прежний кадр верха удерживается два шага по 80 мс; его темп сохранён. Палитра GIF ограничена 256 цветами только для предпросмотра.

Проверены размеры, прозрачность, различие восьми боковых кадров и их областей ног, опорная строка и параметры GIF. По контрольным суммам подтверждено, что исходник, игровой PNG и GIF ходьбы вверх, а также весь `src/` остались неизменными. Игровой код, подключённая ходьба вниз, неподвижные ракурсы и меню не менялись.
