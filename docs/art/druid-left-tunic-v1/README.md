# Туника левого ракурса

Стоящий PNG и четыре кадра ходьбы взяты из `druid-facing-fixes-v1`. Исправлены только RGB панелей нательной одежды: приглушённая середина и зелёные боковые части, по принятому `druid-eight-way-v1/idle-down-256x320.png`. Бежевая отделка подола сохранена.

Маски `*-left-tunic-mask.png` показывают разрешённую область изменения. Весь alpha и пиксели вне масок совпадают с предыдущими: плащ, руки, ноги, посох, лицо, пояс и шаг не перерисованы. Один общий перенос палитры используется для стойки и всех фаз ходьбы.

Левая реакция на попадание получила ту же цветовую правку, чтобы одежда не возвращалась к старой бежевой версии после укуса. Её исходные силуэты, сапоги и движение сохранены; первая и последняя позы точно совпадают с новой стойкой. Отдельная маска подтверждает изменение только ткани туники во всех пяти кадрах.

Воспроизведение: `python scripts/prepare-druid-left-tunic.py` (Pillow, NumPy, SciPy). Игра использует PNG, GIF — только для просмотра. Предыдущие файлы сохранены, другие ракурсы и касты не меняются.
