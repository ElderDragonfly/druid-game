# Правая походка из принятых левых ног

Четыре фазы 256×320, по 240 мс при базовой скорости: полный цикл 960 мс, как у движения влево. Источник ног — `../druid-side-refinement-v1/walk-left-body-256x320.png`, тот же рисунок штанов и сапог, что в принятой левой походке, но без перекрывающих руки/посоха.

Из каждой фазы выделена коричневая нижняя часть. Штаны и сапоги отражены горизонтально в исходной сетке 256×320, без перемещения, масштабирования, изменения поз, палитры или промежуточной деформации. Ниже y=268 сохраняется весь контур сапог до последнего непрозрачного пикселя. Маска `left-leg-mask-256x320.png` позволяет проверить сохранение исходных RGB и отражение каждого пикселя.

Справа подол туники другой, поэтому маленький слой `hip-join-256x320.png` соединяет верх штанов с ним, используя только текстуру из отражённой фазы. Он заканчивается на y=238 и не содержит коленей/сапог. Слои: прежний дальний посох → отражённые ноги → соединение под подолом → прежняя правая одежда. Старых ног в одежде нет ниже y=268. Выше y=220 итог в точности совпадает с принятым правым корпусом. Руки, посох, плащ, стоящая поза, размер и физика не меняются.

Подготовка: `python scripts/prepare-druid-right-mirrored.py` (Pillow, NumPy, SciPy). Игра загружает итоговую полосу с NEAREST. GIF и контактный лист служат просмотром; предыдущие v2/v3 остаются архивом.
