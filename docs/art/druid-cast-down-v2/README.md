# Медленный наклонённый полукруг посохом

Архив второй пробы: пользователь отклонил движение. Подготовлен [новый вариант по присланному видеореференсу](../druid-cast-down-v3/README.md). В игру не подключён.

- [Посмотреть GIF](cast-down-preview.gif).
- [Ключевые кадры рядом](cast-down-keyframes.png).
- [Прозрачный лист всех кадров](cast-down-sheet.png).

Друид наклоняет посох от себя примерно на **45°**. Нижний конец остаётся ближе к фигуре, а навершие неспешно проходит небольшую дугу перед грудью справа налево, после чего посох возвращается в исходное положение. Дуга имеет наклон и глубину; при обращении посоха к зрителю видно перспективное сокращение.

## Что изменено после первой пробы

**Корпус больше не перерисовывается по кадрам.** Во всех фазах используется один неподвижный слой из утверждённого [игрового стоящего друида](../druid-front-refinement-v2/idle-down-256x320.png). Его лицо, капюшон, пояс, основная ткань и ноги сохраняют исходные пиксели. Только небольшой участок, прежде закрытый левой рукой и посохом, заполнен тканью из отдельного исправленного рисунка. За пределами маски этого участка исходные пиксели сохраняются точно. Ширина корпуса, масштаб и положение не меняются во время жеста.

Левая рука и один принятый посох — отдельные слои. Рука сгибается в локте с постоянными длинами частей; белый рукав находится под краем плаща. Кисть перекрывает стержень в месте хвата. Верхний конец самого вырезанного посоха привязан к траектории дуги, поэтому она описывается его навершием. Форма развилки и исходные цвета дерева общие для всех кадров. Вторая рука остаётся свободной.

**Темп значительно медленнее:** наклон **300 мс**, полукруг **1800 мс**, возвращение **700 мс**. Весь жест — **2800 мс** вместо 670 мс в первой пробе. С паузами для просмотра полный повтор — **3950 мс**. Ускорение и замедление плавные, резкого ударного рывка нет.

## Файлы и параметры

- GIF: **58 кадров**, 512×384; движущиеся фазы по **50 мс**.
- `cast-down-sheet.png`: 6 столбцов × 10 строк, кадр **512×384**, первые 58 ячеек заняты. Сам герой сохраняет исходную детализацию около 280 пикселей по высоте; вокруг него добавлены поля для движения посоха.
- `body-fixed-256x320.png` — один общий неподвижный корпус.
- `body-clean-source.png` — рисунок скрытой ткани; применяется только локально через `body-edit-mask.png`.
- `upper-arm-256x320.png`, `forearm-256x320.png`, `hand-256x320.png` — части левой руки, выделенные из ранее нарисованной позы.
- `staff-master-256x320.png` — тот же посох, что в v1.
- [art.json](art.json) — длительности, фазы, точки хвата, привязки и контрольная сумма неподвижного корпуса.

Пересборка: `python scripts/prepare-druid-cast-down-v2.py` (Pillow, NumPy, SciPy). Проверяются исходные пиксели вне локальной маски, неизменность лица во всех кадрах, постоянные длины руки, последовательная дуга навершия, примерный пространственный наклон, прозрачность, отсутствие обрезания и длительность GIF. Все 58 кадров дополнительно проверены на отсутствие отдельных висящих фрагментов. Первый и последний кадры — точный исходный стоящий PNG.

Изменяются только материалы для просмотра. Утверждённая игровая ходьба, меню и механики прежние. [Первая проба](../druid-cast-down-v1/README.md) сохранена как архив.
