# Уменьшенные брёвна без тени

Активная версия после уточнений пользователя. Стоящие деревья не изменены.

Пять рисунков доработаны по исходным брёвнам v1 с разрешённой перерисовкой коры и мха. Убрана серая подложка. Это художественная доработка, а не точная пиксельная копия исходного референса. `refined-source.png` сохраняет промежуточный рисунок; `scripts/prepare-refined-logs.py` выделяет пять объектов и собирает отдельные PNG с бинарной прозрачностью, NEAREST и сеткой **2 мировые единицы на пиксель**. Ширина уменьшена до **2/3** прежней, округление не больше одной мировой единицы. Исходные v1 сохранены.

`sprites.json` хранит размеры, общий масштаб, линии столкновения и полигон поверхности для случайных грибов. Три старые точки оставлены для прежних сейвов. Грибы взяты из v1, их масштаб тоже уменьшен до 2/3. Повороты и отражение отключены, в том числе при продолжении старого забега. Позиции и виды грибов в сейве сохраняются.

Сейчас включена тестовая раскладка: **4 разных бревна из пяти вокруг старта**, центры ±220/±135, разброс ±12/±10. На первом гарантированы **1–3 гриба**, у остальных **50% шанс** на 1–3 одного вида из семи. Точки случайны в `mushroomSurface`, с расстоянием ≥6 native-пикселей и разницей x ≥4. Три гриба не стоят на одной прямой. Участки свободны от крон; деревьев **70–99**.

`E` собирает один ближайший гриб до 44 мировых единиц от центра тела, без автоповтора и контакта. Результат сохраняется в планировке, без инвентаря/счётчиков. Старые записи без координат используют прежний `slot`.

`FALLEN_LOG_GENERATION.testAroundSpawn=false` возвращает **2–4 бревна по миру**, шанс грибов 50% у каждого. Коллизии древесины общие для героя, животных и желудей. Сохранённые позиции не меняются; новая раскладка появляется в новом забеге/R.
