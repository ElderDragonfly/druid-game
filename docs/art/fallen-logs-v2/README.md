# Уменьшенные брёвна без тени

Активная версия после уточнений пользователя. Стоящие деревья не изменены.

Пять рисунков доработаны по исходным брёвнам v1 с разрешённой перерисовкой коры и мха. Убрана серая подложка. Это художественная доработка, а не точная пиксельная копия исходного референса. `refined-source.png` сохраняет промежуточный рисунок; `scripts/prepare-refined-logs.py` выделяет пять объектов и собирает отдельные PNG с бинарной прозрачностью, NEAREST и сеткой **2 мировые единицы на пиксель**. Ширина уменьшена до **2/3** прежней, округление не больше одной мировой единицы. Исходные v1 сохранены.

`sprites.json` хранит размеры, общий масштаб, линии столкновения и три места роста грибов. Грибы взяты из v1, их масштаб тоже уменьшен до 2/3. Повороты и отражение отключены, в том числе при продолжении старого забега. Позиции и виды грибов в сейве сохраняются.

Генерация: **2–4 бревна**, равновероятный выбор из пяти вариантов. У каждого **50% шанс** получить **1–3 гриба одного вида** из семи. Размещение вне старта, крон и других брёвен. Деревья используют прежний независимый поток seed, **70–99** на локацию. Коллизии вдоль древесины общие для героя, животных и желудей.
