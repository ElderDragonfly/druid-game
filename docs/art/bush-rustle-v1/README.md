# Шевеление куста — отдельный временный образец

`bush-rustle-preview.gif` — зацикленная GIF для оценки предупреждения: листва шевелится, будто внутри кто-то прячется. Для прототипа выбран компактный `forest-bushes-v2/bush-2.png`. Существующие игровые растения не заменялись, пул генерации не менялся.

Шесть фаз перерисованы по этому кусту нейросетью, это новый анимационный эскиз, а не точная копия исходных пикселей. Змея, глаза, руки и части окружения не добавлены. `generated-sheet.png` сохраняет исходный результат генерации. Кадры механически разделены, приведены к общей опоре и размеру 128×128; низ силуэта неподвижен. Для чёткого контура полупрозрачность переведена в бинарную маску, уменьшение — NEAREST.

`frame-0.png` … `frame-5.png` — прозрачные кадры, `rustle-atlas.png` — шесть ячеек 128×128. GIF показывает их в порядке 0,1,2,3,4,5,4,3,2,1: 450 мс покоя, затем по 120 мс, цикл 1,53 с. Просмотр увеличен в 4 раза, фон однотонный тёмно-зелёный; общая палитра GIF исключает мерцание из-за смены цветовой таблицы. Это демонстрационный темп, будущая длительность предупреждения ещё не утверждена.

В игру не подключено. Код, баланс и сохранения не менялись. Проверены декодирование GIF, бесконечный цикл, длительности, одинаковые размеры кадров и совпадение нижней опоры.
