# Архив исходных вырезок брёвен

Здесь сохранены пять прозрачных брёвен из `../27935983a1221547afe93ab842633fc4.jpg` и `../e61f996047ae8b58748b8ca5559c9323.jpg`. Их исходные RGB не менялись. `sprites.json` хранит размеры, масштаб, геометрию и хеши двух референсов; подготовка — `python scripts/prepare-fallen-logs.py`.

В игре используются уменьшенные брёвна без серой тени из [v2](../fallen-logs-v2/README.md). Все прежние грибы, их общая коллекция и старый растительный исходник удалены по просьбе пользователя. Активны только [два новых вида](../log-mushrooms-v3/README.md), независимо от архивных брёвен.
