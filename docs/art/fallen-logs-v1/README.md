# Брёвна и грибы из референсов пользователя

Архив первой версии. Активные уменьшенные брёвна без тени описаны в [v2](../fallen-logs-v2/README.md); грибные PNG этой папки продолжают использоваться с уменьшенным масштабом. Ниже сохранено описание прежней версии.

В игру подключены пять отдельных брёвен и семь видов грибов, вырезанных из JPEG:

- `../27935983a1221547afe93ab842633fc4.jpg` — четыре бревна (на референсе указан @KIANAMOSSER).
- `../e61f996047ae8b58748b8ca5559c9323.jpg` — длинный ствол на клетчатом фоне.
- `../d604a2e904ddb3a3efb1c37341c5979c.jpg` — семь грибных элементов; остальные растения не подключены.

`log-0.png`…`log-4.png` и `mushroom-0.png`…`mushroom-6.png` имеют прозрачный фон. Рисунки не генерировались и не перекрашивались. Сохранённые RGB точно совпадают с исходным JPEG; подготовка проверяет это автоматически. Удалены плоский/клетчатый фон и мелкая JPEG-кайма. Для маски используется фильтрация трёхпиксельных шумовых выступов; исходные крупные пиксельные формы сохранены. Тени четырёх брёвен оставлены частью рисунка.

Подготовка: `python3 scripts/prepare-fallen-logs.py` (Pillow, NumPy, SciPy). Выходные размеры, исходные рамки вырезки, SHA-256 референсов, масштаб, линия столкновений и три места роста для каждого бревна находятся в `sprites.json`. `collection.png` — локальная коллекция для проверки; игра загружает отдельные PNG.

На всей локации генерируется **2–4 бревна**, каждое равновероятно выбирается из пяти вариантов. Поворот **−35°…+35°**, зеркальное отражение с вероятностью 50%. Генератор использует отдельный поток seed: добавление брёвен не переставляет существующие деревья. Брёвна не пересекаются между собой, не закрыты кронами и не появляются на старте.

Для каждого бревна отдельно проверяется **50% шанс грибов**. При успехе выбирается **1–3 гриба**, один вид из семи на всё бревно и разные точки роста. Крепления поворачиваются вместе с древесиной, сами грибные спрайты остаются вертикальными. Это декорация, без подбора и боевых характеристик.

Столкновения вдоль древесины собраны из небольших перекрывающихся неподвижных тел. Игрок, мыши, волки, их маршруты и желуди используют одну геометрию; пустые углы повёрнутого рисунка остаются проходимыми. Грибы не создают дополнительных тел. Положение, поворот, отражение и грибы сохраняются внутри планировки забега; старые сейвы без брёвен продолжают загружаться.
