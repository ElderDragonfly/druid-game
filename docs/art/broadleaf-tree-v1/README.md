# Лиственное дерево из нового референса

[Исходный JPEG](../4e86ea700a01cfabe8102492566677b2.jpg) · [Прозрачный PNG](broadleaf.png) · [Размеры и опора](sprite.json)

Дерево вырезано из исходника механически. Удалены только связанный с внешней границей фон, JPEG-ореол по контуру и выступающая горизонтальная линия земли у корней. Цвета оставшихся непрозрачных пикселей точно совпадают с JPEG; палитра, ствол и внутренняя крона не перерисованы.

PNG — 440×714, масштаб 0,375 с NEAREST, в игре 165×267,75 единицы. Опора (227,712) у основания ствола. Рабочая коллизия 36×4 располагается на 14–18 единиц выше опоры; крона не блокирует движение. PNG и параметры хранятся отдельно от генератора.

На всей локации генерируется **70–99 деревьев включительно**. Каждое место независимо выбирает с равной вероятностью это дерево или прежнюю тёмно-зелёную сосну. Четыре старых архивных варианта не входят в пул. Между физическими основаниями сохраняется зазор 28 единиц; старт и границы свободны, расположение воспроизводится по seed.

Повторная подготовка: `python scripts/prepare-broadleaf-tree.py` (Pillow). Координаты исходной вырезки и параметры отделения фона сохранены в `sprite.json`.
