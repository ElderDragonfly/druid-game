# Медведь — пробная ходьба

Первоначальное превью для оценки; теперь его кадры используются в игре.

- [GIF спокойной ходьбы](bear-walk-preview.gif) — 8 кадров по 160 мс, цикл 1280 мс, повтор без остановки, размер просмотра 384×320.
- [Все фазы](walk-frames.png) — 4×2, увеличено без сглаживания.
- `walk-00.png` … `walk-07.png` — отдельные прозрачные ячейки 96×80.
- `walk-sheet.png` — горизонтальный атлас, `animation.json` — размеры, длительности и опоры.

Образ взят из пользовательского `../7f3bc9083f8614b16f7bdff957d5eb17.jpg`: массивный бурый медведь, охристая шерсть на спине, зелёный мох, светлый грибок у головы и тёмные лапы. Сохранён исходный ракурс влево вполоборота. `../08f30658094e60df6fabc4dd417168c3.jpg` и `../abd1f9552d1a3b5fd43d3a521295b800.jpg` использованы как приблизительные схемы движения.

В загруженных файлах нет готовых кадров этого мшистого медведя. Восемь фаз **дорисованы по референсам**, исходные JPEG не менялись. Новый лист `walk-source.png` сохранён отдельно: это не извлечённая из референса готовая анимация. В цикле лапы переносят вес поочерёдно, есть небольшое движение плеч и головы.

Сборка: `python scripts/prepare-bear-walk.py` (Pillow, NumPy). Скрипт механически нарезает лист, уменьшает все ячейки с одним масштабом NEAREST, выравнивает верх корпуса и линию опоры, сохраняет прозрачные PNG и собирает GIF с общей палитрой. Отдельные части тела скрипт не дорисовывает. Проверяются восемь разных кадров, отсутствие обрезанных краёв, размеры GIF, длительность каждого кадра и зацикливание.

## Ходьба вправо

[GIF вправо](bear-walk-right-preview.gif) — точное горизонтальное отражение прежнего цикла влево: те же восемь фаз по 160 мс. `walk-right-00.png` … `walk-right-07.png`, `walk-right-sheet.png`, `animation-right.json` подготовлены отдельно. Ни один старый левый кадр не изменён. `python scripts/prepare-bear-right-walk.py` проверяет совпадение всех RGBA-пикселей PNG и RGB-пикселей отображаемого GIF с отражением исходных кадров, включая длительности. Перерисовки для правой стороны нет.
