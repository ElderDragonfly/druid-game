# Перестановка ног при ходьбе вправо

В игре подключена полоса `walk-right-256x320.png`: четыре кадра 256×320. Исправлена только нижняя часть правого цикла. За основу взяты принятые ноги из отдельного слоя левой походки без посоха; развёрнуты только ноги, чтобы посох остался в своей анатомической руке. Прежние туника, плащ, верх, рука и дальний посох перекрывают ноги в исходном порядке.

Сборка: `python scripts/prepare-druid-right-steps.py` (Pillow, NumPy, SciPy). Верх до y=220 сохраняется пиксель в пиксель. Стоящий ракурс вправо и остальные направления не менялись. Скорость и темп прежние: четыре фазы по 240 мс при базовой скорости друида; игровой темп зависит от скорости перемещения. GIF служит просмотром, игра использует PNG-полосу.

Исправление выреза: маска плаща больше не захватывает тёплые оттенки внутри сапога. Под подолом сохраняется правая часть штанов там, где у левого донора нога была закрыта своим плащом. Ступни продолжают принятый цикл шага.
