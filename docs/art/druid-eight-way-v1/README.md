[Все стоящие ракурсы рядом](idle-eight-directions-preview.png). Полосы ходьбы называются `walk-{направление}-256x320.png`, кадры рядом на фоне — `walk-{направление}-frames-preview.png`. GIF всех направлений используют единую палитру без дизеринга; PNG сохраняют полные цвета.

Образец цвета плаща — утверждённый [стоящий лицом к игроку](../druid-front-refinement-v2/idle-down-256x320.png). Его новый PNG совпадает с исходником побайтно. Для ткани остальных поз используется один набор точных RGB из этого изображения и фиксированная таблица переноса светлоты на направление, общая для стоящей позы и четырёх фаз. Оттенок не подбирается заново для каждого кадра. Лицо, дерево посоха, борода и сапоги этим переносом не перекрашиваются.

Неподвижные боковые позы нарисованы отдельно: обе ноги опущены, плащ свисает, шаг не замирает на середине. Вверх под принятым плащом стоят новые ноги с более широкой асимметричной расстановкой. Одна стопа немного дальше по плоскости земли, как у принятого фронтального образца.

Вверх сохранены принятые ноги, свободная рука и рука с посохом. В области плеч и ткани используются новые нарисованные складки; два плеча чуть поворачиваются навстречу шагу, до 1,8 пикселя по Y в противоположных фазах. Голова и весь герой не качаются целиком. [Пользовательский референс из архива](user-up-reference.png) использован как образец движения плеч; архивный текст не исполняется как инструкции проекта. Влево свободная дальняя правая кисть кратко выглядывает из-за переднего края тела; рука с посохом сохранена.

Для диагоналей нарисованы четыре самостоятельных ракурса корпуса, плеч, ткани и свободной руки. Поскольку исходные рисунки местами повторяли ведущую ногу, под них подставлены принятые полные фазы ног фронтального/заднего набора: они действительно чередуют опорные стопы. Привязка к тазу сохранена, небольшой сдвиг по X (0,14 пикселя на пиксель высоты ниже y=217) согласует постановку ног с диагональным ракурсом. Ноги не отделяются только от колен. Посох остаётся в анатомически левой руке: слева она ближняя, справа дальняя. Один вырезанный слой руки/посоха переносится целиком, подъём 0/6/12/6: одна опора за два шага. Для вверх-вправо используется полный принятый слой дальней руки из предыдущего бокового набора, чтобы не брать перекрывающие его сапоги с исходной стоящей фигуры. Небольшие изменения складок и подола присутствуют в нарисованных фазах.

`EightWayFacing` выбирает направление по суммарному вводу WASD. Противоположные клавиши отменяются, скорость диагонали нормализуется. При отсутствии ввода сохраняется последний ракурс. `Druid` включает цикл сразу, а после остановки запоминает следующую фазу: повторные короткие нажатия продолжают чередование поз вместо постоянного возврата к первому кадру. При отпускании клавиш движение сразу прекращается и показывается отдельная стоящая поза.

## Источники и сборка

- `idle-turnaround-source.png` — нарисованные стоящие ракурсы; фронтальный итоговый кадр из него не используется.
- `walk-{диагональ}-body-source.png` — четыре нарисованные фазы тела без руки с посохом.
- `walk-alternate-step-source.png` — дополнительные позы корпуса/плаща/свободной руки для третьих фаз диагональных циклов; ноги берутся из принятой ходьбы вниз/вверх.
- `walk-up-shoulders-source.png` — новые фазы плеч и ткани; ноги из этого листа не подставляются.
- `arm-staff-{диагональ}.png` — вырезанные слои руки/ветки.
- Прежние принятые фронтальные, задние и боковые наборы остаются в соседних папках и используются для соответствующих слоёв. Меню, портрет и окружение не менялись.

Повторная сборка: `python scripts/prepare-druid-eight-way.py` (Pillow, NumPy, SciPy). Метаданные — [art.json](art.json). Обработка собирает нарисованные позы, выравнивает сетку и переносит палитру; новые ракурсы не получаются отражением старых.
