# Друид: единый лист четырёх ракурсов

Новая проба по [друиду из указанного эскиза поляны](../druid-detail-preview-v1/gameplay-druid-preview.png). Предыдущие четыре отдельных спрайта отклонены за чрезмерное упрощение и удалены.

[Открыть картинку в полном размере](druid-four-views.png)

<img src="druid-four-views.png" alt="Один лист: друид спереди, слева, справа и со спины" width="1000">

Порядок ракурсов:

| | Слева | Справа |
| --- | --- | --- |
| Верхний ряд | Лицом к игроку | Смотрит влево |
| Нижний ряд | Смотрит вправо | Спиной к игроку |

Это **одна исходная картинка 1254×1254**, с четырьмя фигурами на прозрачном фоне. Сохранена непосредственно из генерации: без нарезки на кадры, уменьшения пиксельной сетки, ограничения палитры или последующего упрощения. Художественный запрос — сохранить образ из эскиза и яснее показать лицо, бороду, складки одежды, сапоги и фактуру ветки-посоха.

Посох остаётся в левой руке друида, как в исходном эскизе: спереди — справа для зрителя, со спины — слева. Для боковых видов задан поворот всего тела вместе с головой и ногами. Этот лист ещё предстоит оценить по сходству, детализации и согласованности ракурсов; это не утверждённые анимационные кадры.

В игру лист не подключён. Меню, игровой спрайт и управление не изменены. Для скачивания откройте PNG на GitHub и нажмите «Download raw file». После `git pull --ff-only` он находится в `docs/art/druid-turnaround-v3/druid-four-views.png`.
