# Волк — анимации для просмотра

- [Агрессивный бег — второй ряд исходника](wolf-run.gif): 5 кадров по 90 мс, цикл 450 мс. Волк заметил цель и бежит к ней. В предпросмотре сохранены капли слюны и тень из исходника.
- [Спокойная ходьба — третий ряд исходника](wolf-walk.gif): 6 кадров по 150 мс, цикл 900 мс. Волк бродит, пока не заметил персонажа. Сохранены исходные позы и тень; утверждённый агрессивный бег не изменён.
- [Стояние — предпоследний, шестой ряд](wolf-idle.gif): 6 кадров по 200 мс, цикл 1,2 с. Небольшие исходные движения ушей, головы и пасти; корпус и лапы выровнены, чтобы фигура не смещалась из-за изменения силуэта головы.
- [Атака вверх — четвёртый ряд](wolf-attack-up.gif): начальная стойка из пятого ряда, затем три кадра четвёртого ряда слева направо.
- [Атака вниз — пятый ряд](wolf-attack-down.gif): начальная стойка и три последующих кадра пятого ряда слева направо.
- [Смерть — последний, седьмой ряд](wolf-death.gif): 7 кадров; падение занимает 620 мс, последний кадр удерживается 1,2 с, затем предпросмотр повторяется. Нарезка переделана из исходника: третий кадр включает всю заднюю часть тела, которую обрезала прежняя рамка.

Все GIF увеличены ×3 без сглаживания и показываются на однотонном лесном фоне. Темп выбран для первого просмотра: JPEG не содержит исходных длительностей кадров. GIF зациклены для сравнения; в игре бег обычно повторяется, атака и смерть проигрываются один раз, после смерти сохраняется последний кадр.

У обеих новых атак по четыре кадра: **240/100/100/220 мс**, всего **660 мс**. Первый кадр и его тень одинаковы в обеих последовательностях. Пауза в начальной стойке помогает увидеть начало движения; GIF повторяются только для просмотра.

Для будущего подключения подготовлены прозрачные PNG-листы с общей сеткой **128×112** и опорой (64, 100): [бег](wolf-run.png), [ходьба](wolf-walk.png), [стояние](wolf-idle.png), [атака вверх](wolf-attack-up.png), [атака вниз](wolf-attack-down.png), [смерть](wolf-death.png). У бега, ходьбы и смерти сохранена общая линия земли каждого исходного ряда, поэтому вертикальные движения тела не выравниваются искусственно. Координаты вырезок, положения кадров и длительности находятся в [animations.json](animations.json).

У бега слюна входит в PNG самого волка; отдельные тёмные капли под пастью сохранены независимо от их связи с силуэтом. [Тень бега](wolf-run-shadow.png) вынесена в отдельный слой той же сетки. Её форма взята из исходника, полупрозрачность восстановлена по затемнению шахматного фона. Чистый фон справа от волка даёт образец той же фазы шахматки; случайные изолированные JPEG-пятна отбрасываются. Это восстановленная тень из JPEG, не исходный альфа-канал художника. GIF показывает оба слоя вместе.

У ходьбы также есть отдельный [слой исходной тени](wolf-walk-shadow.png). Для восстановления используются свободные от волков полосы слева и справа от третьего ряда. В третьем кадре удалён замкнутый участок шахматки между скрещёнными лапами; мех и цвета сохранены.

У стояния подготовлены [прозрачный PNG-лист](wolf-idle.png) и [отдельный слой тени](wolf-idle-shadow.png), оба с сеткой 128×112. Кадры выровнены по неподвижной части корпуса и лапам, а не по меняющейся ширине общего силуэта; опорные координаты исходника сохранены в `sourceAnchor` каждого кадра в `animations.json`. Цвета рисунка сохранены из JPEG, тень восстановлена тем же способом по свободным полосам справа. В будущей игре стояние должно повторяться циклически (`gameRepeat: -1`); сейчас это только отдельный предпросмотр.

Для новых атак подготовлены прозрачные листы [четвёртого ряда](wolf-attack-up.png) и [пятого ряда](wolf-attack-down.png), а также отдельные слои теней [четвёртого](wolf-attack-up-shadow.png) и [пятого](wolf-attack-down-shadow.png) ряда. Сетка та же — 128×112. Тени восстановлены из исходника по свободным полосам справа; при отделении фона учтено затемнение шахматки под лапами. Отдельные капли возле пасти сохранены. Строки исходника для каждого кадра указаны в `animations.json`, включая общую начальную стойку из пятого ряда.

У смерти есть отдельный [слой исходной тени](wolf-death-shadow.png). Весь ряд привязан к общей линии земли исходника `y=557`; светлая шерсть внутри силуэта сохранена, цвета оставшихся непрозрачных пикселей совпадают с JPEG. Последний кадр предназначен для сохранения в игре после однократного проигрывания (`gameRepeat: 0`). GIF зациклена только для просмотра. Старые `wolf-attack.gif` / `wolf-attack.png` удалены: актуальны две утверждённые направленные атаки. Прежняя нарезка смерти заменена этой версией; остальные утверждённые анимации сохранены без изменений.

Для движения вправо и влево в игре достаточно одного набора кадров: исходник смотрит вправо, для бега влево применяется `flipX`. Тень отражается вместе с волком. Отдельную зеркальную GIF хранить не требуется. Это работает для боковых направлений; вид спереди или сзади потребует собственных рисунков, если такие ракурсы понадобятся.

[Загруженный исходник](../2146238c373cba499284aaad3f0af0f5.jpg) сохранён без изменения. На нём видна подпись `ripped by Maxim`. Рисунок не генерировался заново: кадры вырезаны из JPEG, сохранённые непрозрачные RGB-пиксели совпадают с исходником. Шахматка уже впечатана в JPEG; прозрачность подготовлена маской внешнего фона и удалением отделённых нейтральных фоновых пятен. Это восстановленная прозрачность, а не исходный альфа-канал художника. PNG сохраняют RGB без GIF-квантизации; в GIF палитра ограничена форматом.

Подготовка: `python scripts/prepare-wolf-art.py` (Python 3 + Pillow); только бег — `python scripts/prepare-wolf-art.py --only run`, только ходьба — `python scripts/prepare-wolf-art.py --only walk`. Волк **подключён к игре**: ходьба, стояние, бег и обе атаки используют эти PNG без перерисовки; смерть пока хранится для будущего боя. Загрузчик и нарезка — `src/rendering/wolfArt.ts`, характеристики — `src/data/wolf.ts`. GIF остаются только предпросмотрами; игровые кадры выбираются из прозрачных PNG.

Новые атаки можно пересобрать отдельно: `python scripts/prepare-wolf-art.py --only attack-up` и `python scripts/prepare-wolf-art.py --only attack-down`.

Стояние пересобирается отдельно: `python scripts/prepare-wolf-art.py --only idle`. Прочие утверждённые PNG/GIF при этом не изменяются.

Смерть пересобирается отдельно: `python scripts/prepare-wolf-art.py --only death`.
