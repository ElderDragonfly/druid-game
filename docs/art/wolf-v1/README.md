# Волк — три анимации для просмотра

- [Передвижение — бег](wolf-run.gif): 5 кадров по 90 мс, цикл 450 мс.
- [Атака — бросок](wolf-attack.gif): 4 кадра, 250/120/100/220 мс. Взята последовательность из среднего ряда, где волк наклоняется и бросается вперёд.
- [Смерть](wolf-death.gif): 7 кадров; последний удерживается 1,2 с, затем предпросмотр повторяется.

Все GIF увеличены ×3 без сглаживания и показываются на однотонном лесном фоне. Темп выбран для первого просмотра: JPEG не содержит исходных длительностей кадров. GIF зациклены для сравнения; в игре бег обычно повторяется, атака и смерть проигрываются один раз, после смерти сохраняется последний кадр.

Для будущего подключения подготовлены прозрачные PNG-листы с общей сеткой **128×112** и опорой (64, 100): [бег](wolf-run.png), [атака](wolf-attack.png), [смерть](wolf-death.png). Во время бега сохранена общая линия земли исходного ряда, поэтому воздушные фазы не опускаются к земле искусственно. Координаты вырезок, положения кадров и длительности находятся в [animations.json](animations.json).

[Загруженный исходник](../2146238c373cba499284aaad3f0af0f5.jpg) сохранён без изменения. На нём видна подпись `ripped by Maxim`. Рисунок не генерировался заново: кадры вырезаны из JPEG, сохранённые непрозрачные RGB-пиксели совпадают с исходником. Шахматка уже впечатана в JPEG; прозрачность подготовлена маской внешнего фона и удалением отделённых нейтральных фоновых пятен. Это восстановленная прозрачность, а не исходный альфа-канал художника. PNG сохраняют RGB без GIF-квантизации; в GIF палитра ограничена форматом.

Подготовка: `python scripts/prepare-wolf-art.py` (Python 3 + Pillow). Волк пока **не подключён к игре**; персонаж, мышь и окружение не менялись.
