Для каждого нового ракурса нарисованы шесть фаз корпуса/левой руки. Ракурсы самостоятельные, без зеркального переноса посоха в другую руку. Посох — один исходный вырезанный слой из v1; он поворачивается у места хвата. В дальних ракурсах корпус и цельный слой плаща перекрывают руку и древко; кисть перекрывает место хвата. В заднем восстановлении вместо ошибочно нарисованной правой руки переиспользована правильная левая поза раскрытия. Цвет ткани приведён к исходной тёплой палитре, штаны и обувь — к принятым тёмным цветам.

## В игре

- **Стрелки** запускают жест в своём направлении; две соседние — по диагонали. Направление атаки не зависит от WASD.
- Короткое нажатие запускает полный жест, удержание повторяет его. Противоположные стрелки взаимно отменяются.
- Внутри жеста можно менять направление; добавление второй стрелки сохраняет текущую фазу.
- Рабочие фазы: шесть кадров по **100, 120, 80, 130, 110, 130 мс**, всего **670 мс**. Длинные паузы из GIF нужны только для просмотра.
- После отпускания текущий жест заканчивается, затем показывается стоящий или идущий друид по актуальному вводу. Потеря фокуса отменяет жест.
- Кадр **512×384**, исходная фигура **256×320** с полями **128 слева и 40 сверху**. В игре прежний масштаб `87.5 / 256`, NEAREST; большая прозрачная рамка не увеличивает героя. Физическое тело остаётся **20×25**.
- Это пока анимация заклинания; снаряды, урон и эффекты не добавлены. Во время каста друид останавливается; после завершения ходьба возобновляется, если WASD всё ещё зажата. Удержание стрелок повторяет каст на месте.

Управление — `RoomScene`, независимый таймер фаз — `DruidCasting`, регистрация картинок — `druidCastArt`, сменяемый визуальный слой — `Druid`. Связь с персонажем хранится в `CharacterDefinition.game.casts`. Физическое тело и камера не меняются при смене рисунка.

Пересборка исходной версии: `python scripts/prepare-druid-cast-eight-way.py` (Pillow, NumPy, SciPy). Для действующих правых ракурсов используется отдельный `prepare-druid-right-casts.py`. [art.json](art.json) хранит параметры исходной версии. Проверки: `npm run build`, `npm test`; браузерные проверки сверяют пиксели восьми текстур с PNG, все направления через реальные клавиши, короткое нажатие, повтор, смену диагонали, остановку во время каста и возобновление ходьбы, стойку, опору ног, коллайдер, потерю фокуса и перезапуск.
