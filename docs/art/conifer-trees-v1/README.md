# Четыре стоящих дерева

Четыре хвойных дерева механически вырезаны из [загруженного исходника](../DarbxwNV4AAsS-l.jpg) и **отложены: исключены из активного пула генерации**. Все PNG и данные каталога сохранены. Взяты только стоящие деревья верхнего ряда, слева направо; пеньки и лежащие деревья не включены. Ранее сгенерированные варианты заменены. На референсе указано `@KIANAMOSSER`. [Исходная публикация](https://x.com/kianamosser/status/984841145921429504/photo/1).

Первоначальный исходник — JPEG 840×840. Основа текущей обработки — сами принятые PNG из `4e1d475`, до попыток очистки: их исходный атлас и метаданные сохранены в [approved-source](approved-source). Скрипт читает эти кадры напрямую. Удалены только **109 светлых нейтральных точек на наружном силуэте**. Отдельная защитная маска закрывает промежутки между крайними пикселями каждой строки и каждого столбца, чтобы даже открытые просветы между ветками не считались наружным контуром. Она используется только для защиты, а не для заполнения изображения. Все остальные RGBA-пиксели точно совпадают с принятыми PNG, включая внутренние пиксели и исходные просветы. Осталось **122 860 непрозрачных пикселей**. Каждый PNG имеет прозрачность 0/255 и свободные поля по 8 пикселей. Рисунки в [trees-atlas.png](trees-atlas.png) совпадают с отдельными PNG пиксель в пиксель. Подложка предпросмотра не входит в игровые изображения.

[sprites.json](sprites.json) задаёт кадры атласа, точки опоры, размеры оснований и масштаб 0,6875. Размеры PNG — 176×331, 217×394, 176×331 и 217×396; настроенная высота — примерно 228–272 игровых единицы. Сейчас на локации **0 деревьев**. При явном включении архивного пула генератор по-прежнему поддерживает **45–63 включительно** со случайными позициями и вариантами по всей площади. Столкновения относятся к основаниям стволов (60×19 игровых единиц), кроны остаются навесами. Активный пул задаётся отдельно через `TREE_SPAWN_POOL` в `src/data/environment.ts`.

Отдельные кусты и камни удалены из игры. Земля использует принятую [тёмную лесную подстилку](../forest-floor-v1/README.md), собранную по seed из случайных фрагментов. Мир 3840×2160, овальная камера и анимации друида сохраняются.

Очистку можно повторить командой `python scripts/prepare-conifer-art.py` из корня репозитория (Python 3 и Pillow; для запуска игры не нужны). Скрипт проверяет RGBA каждого неизменяемого пикселя против принятого PNG. Координаты нарезки, SHA-256 исходника и сохранённого атласа записаны в `sprites.json`. Игровые проверки сравнивают каждый пиксель загруженных кадров с PNG и проверяют генерацию, движение и столкновения.
