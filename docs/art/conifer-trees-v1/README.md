# Четыре стоящих дерева

Четыре хвойных дерева механически вырезаны из [загруженного исходника](../DarbxwNV4AAsS-l.jpg) и подключены к игре. Взяты только стоящие деревья верхнего ряда, слева направо; пеньки и лежащие деревья не включены. Ранее сгенерированные варианты заменены. На референсе указано `@KIANAMOSSER`. [Исходная публикация](https://x.com/kianamosser/status/984841145921429504/photo/1).

Исходник — JPEG 840×840. При нарезке меняется только прозрачность: серый фон и одиночные следы JPEG-сжатия удалены. Дополнительно удалены **1 540 пикселей JPEG-ореола и отделившихся от него точек**, соединённых с прозрачным краем; светлые детали внутри рисунка не затрагиваются. Все **121 429 оставшихся непрозрачных пикселей** четырёх PNG сохраняют RGB загруженного файла; рисунок не генерировался заново, не перекрашивался и не масштабировался при подготовке. Каждый PNG имеет прозрачность 0/255 и свободные поля по 8 пикселей. Рисунки в [trees-atlas.png](trees-atlas.png) совпадают с отдельными PNG пиксель в пиксель. Подложка предпросмотра не входит в игровые изображения.

[sprites.json](sprites.json) задаёт кадры атласа, точки опоры, размеры оснований и масштаб 0,6875. Размеры PNG — 176×331, 217×394, 176×331 и 217×396; высота в игре — примерно 228–272 игровых единицы. Количество на локации — **45–63 включительно**, позиции и варианты случайны по всей площади. Столкновения относятся к основаниям стволов (60×19 игровых единиц), кроны остаются навесами.

Отдельные кусты и камни удалены из игры. Прежний фон пола восстановлен, включая его текстуру травы. Мир 3840×2160, овальная камера и анимации друида сохраняются.

Нарезку можно повторить командой `python scripts/prepare-conifer-art.py` из корня репозитория (Python 3 и Pillow; для запуска игры не нужны). Скрипт проверяет RGB каждого сохранённого непрозрачного пикселя против исходника. Координаты нарезки и SHA-256 исходника записаны в `sprites.json`. Игровые проверки сравнивают каждый пиксель загруженных кадров с PNG и проверяют генерацию, движение и столкновения.
