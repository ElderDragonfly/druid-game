# Два новых вида грибов

`mushroom-0.png` — целая группа оранжевых грибов из `../4b0b8db07aff0050267f37040ceb7ed9.jpg`; `mushroom-1.png` — группа из двух розовых грибов из `../7e7fc479fa99796e96ff1fd405f0d0a4.jpg`. Оба референса добавлены пользователем в `78643a3`.

Удалён белый фон, включая промежутки между ножками. У оранжевых шляпок дополнительно убрана наружная светлая JPEG-кайма; настоящая кремовая окантовка второго рисунка сохранена. Все оставшиеся RGB совпадают с JPEG после декодирования Pillow, рисунки не генерируются и не перекрашиваются. Alpha только 0/255, по краям есть прозрачный отступ. `sprites.json` хранит рамки вырезки, размеры, число оставшихся пикселей и SHA-256 исходников.

Подготовка: `python scripts/prepare-log-mushrooms.py` (Pillow, NumPy, SciPy). `collection.png` — просмотр двух отдельных вырезок на тёмном фоне.

Это единственные два вида в игровом пуле. Поверх прежнего масштаба добавлен `MUSHROOM_SIZE_MULTIPLIER=2`: оба спрайта увеличены вдвое по ширине/высоте, высота теперь около 29,33 вместо 14,67 игровых единиц. Нижняя точка остаётся на древесине; PNG и их цвета прежние. На обычном бревне шанс 50% получить 1–3 группы одного вида, позиции случайны по древесине. Временная проверочная раскладка по-прежнему создаёт четыре бревна у старта, первое гарантированно с грибами. Сбор — одно нажатие E рядом с любым участком бревна.

Прежние семь вырезок, их исправленные версии, коллекции и общий растительный JPEG удалены из текущего дерева репозитория. Их индексы в старых сохранениях при загрузке переводятся в два новых вида без изменения координат, точек роста и количества оставшихся грибов.
