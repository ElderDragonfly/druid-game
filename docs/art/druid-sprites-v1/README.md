# Друид: три варианта игрового спрайта

Варианты для выбора внешнего вида героя на поляне. Один ракурс сверху, нейтральная поза в полный рост и сопоставимый масштаб. Основа — зрелый мужчина с капюшоном, неухоженной острой седой бородой, тканевым плащом и посохом из кривой сосновой ветки с листьями и перьями. Ориентир образа — друид из принятого главного меню.

Все три PNG имеют размер **1254×1254** и прозрачный фон. Высота основной непрозрачной фигуры различается не более чем на 5 пикселей. Это исходные варианты для сравнения; после выбора нужно зафиксировать размер игровой пиксельной сетки, точку опоры у ног и подготовить кадры направлений и движений. Изображения сгенерированы по описанию, без изменения действующей игры.

## 1. Лесной странник

Широкий мохово-зелёный плащ, сдержанные тканевые слои и связки растений на поясе. Базовый вариант с наиболее простым силуэтом.

Более светлый шалфейный плащ, льняной нижний слой, заметные связки трав и небольшой мешочек с корнями. Акцент на образе травника.

## 3. Природный маг

Плотный тёмно-зелёный плащ, земляная туника, тканевый пояс и древесный медальон. Акцент на более тяжёлом и зрелом образе.

## Как посмотреть

На GitHub откройте PNG и используйте «Download raw file» для скачивания оригинала. После `git pull --ff-only` эти же файлы находятся в папке `docs/art/druid-sprites-v1` на компьютере. Их можно открыть обычным просмотрщиком изображений.

В игру варианты пока не подключены. Для следующего этапа выбираем один образ или сочетание деталей из нескольких. Затем отдельно согласуем направления, ходьбу и другие движения.
