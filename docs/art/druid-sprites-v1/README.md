# Друид: варианты образа

Добавлен отдельный [**Druid 04 Basic**](druid-04-basic.png) для обсуждения базового образа. Первые три рисунка сохранены без изменений. Новый эскиз пока не подключён к игре; описание ниже сохраняет историю ранее выбранных вариантов.

Из этих вариантов принят **первый — «Лесной странник»**. Исправленный [рабочий образ](../../../src/assets/characters/druid-standing-detail.png) получил отдельную связку корешков слева от зрителя вместо цветов. На экране выбора используется правый лагерь из [явно указанного эскиза](../druid-detail-preview-v1/character-selection-preview.png), без перерисовки. Прежний прозрачный сидящий рисунок сохранён как архив. Главное меню сохраняет прежний вид. Для комнаты позднее принят [подробный лист четырёх ракурсов](../druid-turnaround-v3/README.md), который используется без уменьшения сетки и палитры. Ниже сохранены исходные три варианта для сравнения. Один ракурс сверху, нейтральная поза в полный рост и сопоставимый масштаб. Основа — зрелый мужчина с капюшоном, неухоженной острой седой бородой, тканевым плащом и посохом из кривой сосновой ветки с листьями и перьями. Ориентир образа — друид из принятого главного меню.

Все три PNG имеют размер **1254×1254** и прозрачный фон. Высота основной непрозрачной фигуры различается не более чем на 5 пикселей. Это исходные варианты для сравнения; активные кадры направлений подготовлены по более позднему листу, движения ещё предстоит подготовить. Исходная тройка была сгенерирована отдельно для обсуждения образа; выбранная и исправленная версия теперь используется в игре.

## 1. Лесной странник

Широкий мохово-зелёный плащ, сдержанные тканевые слои и связки растений на поясе. Базовый вариант с наиболее простым силуэтом.

## 2. Травник

Более светлый шалфейный плащ, льняной нижний слой, заметные связки трав и небольшой мешочек с корнями. Акцент на образе травника.

<img src="druid-02-herbalist.png" alt="Вариант 2 — травник" width="480">

## 3. Природный маг

Плотный тёмно-зелёный плащ, земляная туника, тканевый пояс и древесный медальон. Акцент на более тяжёлом и зрелом образе.

[Открыть исходный PNG](druid-03-nature-mage.png)

<img src="druid-03-nature-mage.png" alt="Вариант 3 — природный маг" width="480">

## 4. Базовый друид — Druid 04 Basic

Новая подробная иллюстрация на основе Druid 01 Wanderer: широкий мохово-зелёный плащ, капюшон, седая борода и тканевая одежда. Вместо прежнего пояса — простая верёвка по образцу Herbalist. Убраны сумка, травы, цветы, корешки и медальон. Посох сохранён как голая кривая ветка без листьев, перьев и обвязок. Сапоги без шнуровки.

[Открыть Druid 04 Basic](druid-04-basic.png)

Это отдельный эскиз для утверждения внешности, а не замена Druid 01 и не набор игровых кадров. Фигура, пояс и посох пока находятся в одном прозрачном PNG; независимые сменные слои ещё не подготовлены. Договорённости о слоях и отложенные задачи сохранены в [заметках проекта](../../project-notes.md).

## Как посмотреть

На GitHub откройте PNG и используйте «Download raw file» для скачивания оригинала. После `git pull --ff-only` эти же файлы находятся в папке `docs/art/druid-sprites-v1` на компьютере. Их можно открыть обычным просмотрщиком изображений.

Исправленная версия первого варианта подключена в игру. Следующий художественный этап — отдельно согласовать направления, ходьбу и другие движения.
