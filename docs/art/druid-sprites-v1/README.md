# Друид: варианты образа

Добавлен отдельный [**Druid 04 Basic**](druid-04-basic.png). Образ и перенос палитры утверждены; PNG подключён к маленькой доступной карточке «Друид» на экране выбора. Первые три рисунка, сидящая фигура, фон меню и игровые анимации сохранены. Новые [GIF Basic](../druid-basic-walk-v1/README.md) подготовлены отдельно для оценки. Описание ниже сохраняет историю ранее выбранных вариантов.

Из этих вариантов принят **первый — «Лесной странник»**. Исправленный [рабочий образ](../../../src/assets/characters/druid-standing-detail.png) получил отдельную связку корешков слева от зрителя вместо цветов. На экране выбора используется правый лагерь из [явно указанного эскиза](../druid-detail-preview-v1/character-selection-preview.png), без перерисовки. Прежний прозрачный сидящий рисунок сохранён как архив. Главное меню сохраняет прежний вид. Для комнаты позднее принят [подробный лист четырёх ракурсов](../druid-turnaround-v3/README.md), который используется без уменьшения сетки и палитры. Ниже сохранены исходные три варианта для сравнения. Один ракурс сверху, нейтральная поза в полный рост и сопоставимый масштаб. Основа — зрелый мужчина с капюшоном, неухоженной острой седой бородой, тканевым плащом и посохом из кривой сосновой ветки с листьями и перьями. Ориентир образа — друид из принятого главного меню.

Все три PNG имеют размер **1254×1254** и прозрачный фон. Высота основной непрозрачной фигуры различается не более чем на 5 пикселей. Это исходные варианты для сравнения; активные кадры направлений подготовлены по более позднему листу, движения ещё предстоит подготовить. Исходная тройка была сгенерирована отдельно для обсуждения образа; выбранная и исправленная версия теперь используется в игре.

## 4. Базовый друид — Druid 04 Basic

Новая подробная иллюстрация на основе Druid 01 Wanderer: широкий мохово-зелёный плащ, капюшон, седая борода и тканевая одежда. Вместо прежнего пояса — простая верёвка по образцу Herbalist. Убраны сумка, травы, цветы, корешки и медальон. Посох сохранён как голая кривая ветка без листьев, перьев и обвязок. Сапоги без шнуровки.

[Открыть Druid 04 Basic](druid-04-basic.png)

Basic уточнён по оригинальному Wanderer 01: более выраженная пиксельная фактура, более тёмные цвета плаща и одежды, более узкая фигура по сравнению с первой версией Basic. Верёвочный пояс, сапоги без шнуровки и отсутствие украшений сохранены. Это художественная переработка по референсу, а не точное копирование его пикселей; исходный Wanderer не изменён.

После одобрения образа и пропорций выполнен **числовой перенос палитры из Wanderer 01 без генерации и перерисовки**. Для зелёной ткани и коричневой одежды отдельно сопоставлены распределения оттенка, насыщенности и светлоты по участкам оригинала без украшений. Каждый заменённый RGB взят непосредственно из палитры соответствующей ткани 01. Коррекция ограничена одеждой; лицо, борода, руки, верёвка, сапоги и посох защищены от неё. Все значения прозрачности, размер 1254×1254 и положение пикселей сохранены. В контрольном участке плеча средний RGB — 57,7/61,6/32,0 против 57,4/61,5/31,4 у оригинала. Различия рисунков складок сохраняются: это перенос цветов, а не замена фигуры рисунком 01. Пользователь утвердил эту цветовую версию.

Перенос воспроизводится скриптом [match-druid-palette.py](../../../scripts/match-druid-palette.py): `python scripts/match-druid-palette.py`; проверка готового PNG без записи — `python scripts/match-druid-palette.py --check`. Требуются Python 3, Pillow, NumPy и SciPy; игровые зависимости не изменены. Базовый рисунок берётся из коммита `84c16ba`, поэтому повторный запуск не усиливает коррекцию. При отсутствии этого коммита можно передать сохранённый исходный Basic через `--input путь/к/файлу.png`. Маски и участки образца указаны в скрипте; дополнительных изображений для сравнения в репозиторий не добавлялось.

Это подробная иллюстрация для карточки, а не замена Druid 01 и не набор игровых кадров. Фигура, пояс и посох в этом PNG находятся в одном слое. У новых боковых GIF тело и рука с посохом уже разделены; полноценная смена всей экипировки ещё не подключена. Договорённости о слоях и отложенные задачи сохранены в [заметках проекта](../../project-notes.md).

## Как посмотреть

На GitHub откройте PNG и используйте «Download raw file» для скачивания оригинала. После `git pull --ff-only` эти же файлы находятся в папке `docs/art/druid-sprites-v1` на компьютере. Их можно открыть обычным просмотрщиком изображений.

Исправленная версия первого варианта подключена в игру. Следующий художественный этап — отдельно согласовать направления, ходьбу и другие движения.
