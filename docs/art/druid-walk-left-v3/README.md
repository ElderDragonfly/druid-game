# Ходьба влево: новая проба смены опорной ноги

Работа сейчас идёт только над левым направлением. Этот вариант **не подключён к игре**; прежние отклонённые боковые циклы удалены. Принятая ходьба вверх подключена отдельно и не перерисовывалась.

- [Посмотреть GIF](walk-left-preview.gif).
- [Подробные четыре позы](walk-left-source.png).
- [Полоса кадров 64×80](walk-left-64x80.png).

<img src="walk-left-preview.gif" alt="Новая проба ходьбы друида влево" width="192">

Вместо очередного набора похожих стоек заданы четыре ключевые фазы: ближняя левая нога впереди → она принимает вес, дальняя правая проходит под тазом → дальняя правая нога впереди, ближняя уходит назад → дальняя принимает вес, ближняя проходит под тазом. В широких стойках ноги разнесены, в проходных позах стопа переносимой ноги поднимается. Более светлая ближняя нога и более тёмная дальняя помогают видеть смену опоры. Вторую половину рисунка дополнительно исправили, чтобы передняя стопа не повторяла ту же ногу, что в первом кадре.

По новым замечаниям размах шага сокращён без уменьшения самой фигуры. Сохранены четыре фазы и чередование ближней и дальней ноги. Целевое сокращение — около четверти; оценка расстояния между центрами сапог по границам их рисунка дала следующие значения на сетке 64×80:

| Опорная поза | До правки | После правки | Сокращение |
| --- | --- | --- | --- |
| Первый кадр | ≈28,1 px | ≈22,4 px | ≈20% |
| Третий кадр | ≈31,7 px | ≈24,4 px | ≈23% |

Это оценка изображённых сапог, а не измерение суставов или расстояния перемещения героя. Скорость движения в игре не менялась.

Посох остаётся в анатомически левой, ближней руке во всех кадрах, включая нижний правый. Видны только эта рука и её хват посоха; правая рука скрыта плащом, лишняя рука в первом кадре убрана. Плащ раскрывается в области ног. Рисунок исправлен через генерацию целых поз; отдельные голени не вырезаются, неподвижный торс не накладывается и зеркальные копии не используются. Убедительность шага и хвата оценивается по GIF и исходнику перед интеграцией.

Исходный лист **1254×1254**, два ряда по две фигуры, сохранён без изменений из последней генерации. Порядок кадров — слева направо, сверху вниз. Полоса **256×80** содержит четыре кадра **64×80**. Для всех фигур применяется общий масштаб **1/8**. Горизонтальный ориентир зелёной области капюшона совмещён с x=32, нижняя граница силуэта — с y=75; целые позы помещаются в кадр без обрезания. Цвета PNG не ограничены, альфа — 0 или 255.

GIF увеличен ближайшим соседом до **192×240**, **160 мс на кадр**, полный цикл **640 мс**. Ограничение палитры до 256 цветов относится только к GIF.

Проверены размеры и прозрачность PNG, различие четырёх кадров и областей ног, отсутствие обрезания, общая опорная строка и параметры GIF. Это технические проверки подготовки файлов; художественный результат ещё предстоит выбрать.
