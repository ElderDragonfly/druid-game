# Медведь: игровые кадры

`python scripts/prepare-bear-game.py` переносит уже подготовленные сон, ходьбу, бег и три атаки на общую прозрачную ячейку **160×128**, опора **(80,100)**. Рисунок уменьшается/увеличивается только игровым масштабом 2; в этом скрипте части тела не перерисовываются. Левые исходные PNG сохранены неизменными, правые ячейки — их точное отражение.

- `sleep-left/right.png` — дыхание спящего, исходные три позы 0→1→2→1.
- `wake-left/right.png` — короткий подъём на 800 мс из лежачей позы, фазы вдоха, низкой опорной позы и стойки. Это сборка существующих рисунков, не новая дорисованная анимация пробуждения.
- `walk-left/right.png`, `run-left/right.png` — принятые циклы, в игре темп следует расстоянию.
- `swipe`, `bite`, `slam` в обе стороны — три случайно выбираемых замаха; попадание в фазе контакта из метаданных.

`animations.json` хранит длительности и номера фаз; все листы загружаются без сглаживания (NEAREST). Отдельной анимации смерти пока нет: после победы игра оставляет затемнённую первую лежачую позу без физического тела. Сон и смерть отличаются состоянием поведения, цветом и коллизией.

Тот же скрипт сохраняет в папках исходных превью правые GIF сна/бега/атак и проверяет их покадровое RGB-совпадение с отражением левых. Ходьба вправо уже была подготовлена ранее и сохранена. Это первые игровые версии медведя; сценарий и базовые характеристики описаны в README проекта.
