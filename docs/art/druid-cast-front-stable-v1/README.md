# Касты вниз и вниз-влево с постоянными пропорциями

Каст [вниз](cast-down-preview.gif) принят пользователем и используется без новых изменений. Для вниз-влево позднее убран оставшийся выступ ткани: [действующая версия](../druid-facing-fixes-v1/README.md). Прежняя версия [вниз-влево](cast-down-left-preview.gif) здесь сохранена для возврата. Жест v1 сохранён: шесть фаз руки и того же кривого посоха, те же точки хвата и углы, длительность **670 мс**. Кадр **512×384**, фигура **256×320**, поля **128×40**. Размер героя, физика, управление и остановка во время каста прежние.

Теперь у каждого направления **один неподвижный корпус**, а не шесть отдельно нарисованных тел. Корпус, плащ, свободная рука, пояс, штаны и сапоги не увеличиваются и не меняют постановку между фазами. Двигается только извлечённая из прежних рисунков левая рука с посохом. У корня рукава лежит постоянный край плаща, чтобы рука выходила из-под него.

Для направления **вниз** голова и взгляд скопированы из первой принятой фазы ходьбы вниз — `../druid-eight-way-v1/walk-down-256x320.png`. Вниз-влево сохраняется голова из соответствующей стоящей позы. Жест пока одинаковый, направления читаются по голове и ракурсу постоянной фигуры; новый разворот плеч не добавлялся.

Фронтальная основа переиспользует прежний `../druid-cast-down-v2/body-fixed-256x320.png`: это только скрытая ткань под рукой, **жест v2 не подключён**. Для вниз-влево `body-clean-source.png` дал локальный участок ткани под удалёнными рукой/посохом. За пределами сохранённой маски исходный PNG неизменён. Внутренние пиксели рукава не прореживаются по цвету.

Слои сохранены отдельно: `body-*-fixed-256x320.png`, `arm-*-poses-512x384.png`, `staff-*-poses-512x384.png`; `arm-*-00..05-256x320.png` — исходные выделенные фазы руки. `cast-*-512x384.png` — игровые полосы, `cast-*-keyframes.png` — кадры рядом. Это сборка слоёв, а не растяжение корпуса под каждый кадр.

Прежние версии доступны для возврата и не изменялись:

- [Вниз v1](../druid-cast-down-v1/cast-down-preview.gif).
- [Вниз-влево v1](../druid-cast-eight-way-v1/cast-down-left-preview.gif).

Пересборка: `python scripts/prepare-druid-stable-front-casts.py` (Pillow, NumPy, SciPy). Проверяются связность частей, бинарная прозрачность, отсутствие обрезания, сохранение пикселей ног и локальность ремонта ткани. `npm run build` и `npm test` проверяют реальные игровые текстуры, совпадение сапог со стойкой во всех фазах, голову как в ходьбе вниз и существующие сценарии управления.
