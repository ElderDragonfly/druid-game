# Basic 04: подробная ходьба влево и вправо

Две отдельные GIF для оценки. **В игру пока не подключены**: A/D используют прежние боковые циклы Basic 64×80. Принятые подробные циклы [вниз](../druid-front-refinement-v2/README.md) и [вверх](../druid-back-refinement-v1/README.md) уже подключены к S/W.

- [Ходьба влево — GIF](walk-left-preview.gif), [кадры рядом](walk-left-frames-preview.png).
- [Ходьба вправо — GIF](walk-right-preview.gif), [кадры рядом](walk-right-frames-preview.png).
- Прозрачные полосы: [влево](walk-left-256x320.png), [вправо](walk-right-256x320.png).

Один подробный образ Basic 04: зрелое лицо, капюшон, острая седая борода, тёплый оливковый плащ, простая верёвка, тканевый костюм, сапоги без шнуровки и голый кривой посох. Плащ опускается к сапогам, его складки немного меняются при ходьбе. Четыре фазы на направление: шаг → проходная поза → другой шаг → проходная поза. Голова/капюшон закреплены по одной позе каждого ракурса; весь корпус не подскакивает вслед за стопами. Цвета ткани и обуви согласованы с палитрой Basic 04.

Посох сохраняет **анатомически левую руку** в обоих направлениях. Влево эта рука ближняя: выходит из-под края плаща, посох рисуется перед ногами. Свободная дальняя рука в этом предложении скрыта. Вправо левая рука дальняя, перекрывается телом; видимая ближняя **правая рука свободна** и качается вперёд/назад. Правый цикл нарисован отдельным ракурсом, а не зеркальным отражением левого.

Для каждого ракурса отделён один рисунок предплечья/кисти с посохом. Он переносится целиком: подъём 0 → 6 → 12 → 6 пикселей, одна опора на два шага. Дополнительный перенос при проносе — до 6 пикселей вперёд по направлению движения. Длина, изгибы, хват и пальцы не меняются между кадрами. Верх ближней руки слева дополнительно перекрывается краем плаща.

**256×320 на кадр**, четыре кадра по **240 мс**, цикл **960 мс**, показ ×1. PNG сохраняют полные цвета и альфа 0/255. Две GIF используют одну общую палитру 256 цветов без дизеринга, чтобы цвет при сравнении не менялся.
