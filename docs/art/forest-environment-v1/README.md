# Сохранённая коллекция камней

**Камни убраны из игры.** Эта коллекция из 30 вариантов сохранена в архиве. PNG камней сохранены без изменений.

[Открыть лист целиком](rocks-preview.png)

![Камни с номерами 01–30](rocks-preview.png)

Отдельные файлы находятся в [sprites](sprites/): `rock-01.png` … `rock-30.png`. [rocks-atlas.png](rocks-atlas.png) содержит те же рисунки на прозрачном фоне, без подписей. [sprites.json](sprites.json) перечисляет размеры и координаты кадров. Игровые текстуры и физические препятствия камней больше не создаются.

Прежние деревья и сухой ствол из этой коллекции удалены. Теперь используются [четыре новых хвойных дерева](../conifer-trees-v1/README.md). Отдельных кустов нет; прежний фон пола с текстурой травы восстановлен.
