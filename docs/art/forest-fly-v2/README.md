# Новая муха

Выбранный пользователем источник: `docs/art/21b6e2a5df123c784950d74653ae51a9.gif` (коммит `7e3470d`), 55 кадров по 100 мс. Прежняя муха, её референсы и все созданные варианты удалены по запросу пользователя.

Механическая нарезка: `python scripts/prepare-forest-fly.py`. Однотонный фон удаляется по точному RGB; рабочая область `(250,68)–(538,338)` содержит весь рисунок, включая частицы смерти. Исходные блоки 6×6 восстанавливаются до логических пикселей с проверкой точного обратного увеличения. Рисунок и его палитра не дорисовываются. Ячейка 64×64, опора (33,44), масштаб в мире 1,8.

- `fly.png`: исходные кадры 0–7, полный цикл взмахов 800 мс. Повторяющиеся куски GIF не дублируются. Крылья продолжают двигаться при зависании.
- `attack.png`: кадры 36–43, 800 мс. Попадание в фазе выдвижения жала, через 300 мс.
- `death.png`: кадры 44–54, 1100 мс. Сохранены все зелёные частицы и финальный пустой кадр исходника; муха после этого исчезает. Трупы волков не менялись.

Исходник смотрит влево, вправо применяется только `flipX`, в том числе к атаке и смерти. Верхнего и нижнего ракурсов нет. Превью `*-left-preview.gif`/`*-right-preview.gif` предназначены для GitHub, игра использует те же PNG-кадры.

Нейтральная небольшая тень — отдельный технический слой. При разлёте физическое тело продолжает двигаться по земной плоскости с коллизиями, рисунок выводится отдельно выше по параболе. Жёлудь проходит под мухой до приземления.
