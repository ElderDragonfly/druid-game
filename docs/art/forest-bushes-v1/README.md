# Кусты из последнего референса

Архив первой вырезки. В игре теперь используется [версия без подложек в общей зелёной палитре](../forest-bushes-v2/README.md); эта коллекция сохранена для сравнения и возможного возврата.

Источник: [`df05d851182e3aef99da299fb3ce8cb5.jpg`](../df05d851182e3aef99da299fb3ce8cb5.jpg), пользовательский коммит `8575fb0`. Вырезаны **все восемь** растений: два сверху, три посередине, три снизу.

`python scripts/prepare-bushes.py` механически обрабатывает восемь прямоугольников: убирает однотонный оливковый фон и мелкий шум JPEG. Сохранённые непрозрачные пиксели копируются из JPEG без перекрашивания, перерисовки, сглаживания или изменения размера. Координаты исходных фрагментов находятся в `sprites.json`.

- `bush-0.png` … `bush-7.png` — отдельные прозрачные PNG.
- `collection.png` — коллекция на тёмно-зелёной подложке для просмотра на GitHub.
- `foliage-atlas.png` — кусты для перекрытия персонажа.
- `ground-atlas.png` — яркие травяные подложки снизу, которые остаются под персонажем. Сумма двух слоёв совпадает с отдельным PNG.

Масштаб в игре **1**, фильтр NEAREST. Рисунок JPEG уже содержит заметные пиксельные ступеньки; дополнительно дробить или увеличивать пиксели не стали. Заданы **24–36 кустов** на локацию, равновероятный выбор одного из восьми. Отдельный seed-поток не меняет прежние деревья и сценарные объекты. Проход и снаряды не блокируются; при пересечении с друидом листва непрозрачна и находится над всеми его слоями. Земля остаётся внизу.
