# Первая мышь

Источник — [загруженная GIF](../91f9b8a17e977a2a9d71e0fbc551f757.gif), с подписью `LANCEKIM0806`. Исходный файл сохранён. Фон-шахматка и подпись не входят в игровые кадры.

- `mouse-look-32x32.png`: все 9 кадров оригинального осматривания, без перерисовки цветов. GIF содержит точные блоки 8×8: вырезка (104, 128)–(360, 384) перенесена в сетку 32×32, два цвета фона стали прозрачными. Длительности кадров: 1000, 100, 1000, 100, 1000, 100, 1000, 100, 1000 мс; всего 5,4 с.
- `mouse-motion-source.png`: новый рисунок четырёх фаз бега и четырёх фаз подъёма, созданный по вырезанному оригиналу.
- `mouse-run-32x32.png`: четыре фазы бега на четырёх лапах, по 100 мс, цикл 400 мс.
- `mouse-rise-32x32.png`: четыре фазы подъёма по 90 мс; последний кадр заменён точным первым кадром оригинальной GIF, чтобы переход к осматриванию сохранял выбранную мышь. Обратный порядок используется для опускания на четыре лапы.

Только новый рисунок движения уменьшен с NEAREST и приведён к палитре оригинала. Прозрачность игровых PNG — 0/255. Точка опоры всех фаз — (16, 25), масштаб 1,875; стоящая мышь имеет видимую высоту около 34 игровых единиц, примерно треть друида. Физическое основание 14×8. Для движения вправо используется отражение; при движении по вертикали сохраняется боковой вид, без поворота всей картинки.

Повторная подготовка: `python scripts/prepare-mouse-art.py` (Python 3 + Pillow; для запуска игры не требуется). Метаданные вырезки — `source.json`.

В игре ровно одна мышь. Обычное появление — на расстоянии 100–160 единиц от старта, без перекрытия деревьями; если за 256 попыток видимое место не найдено, используется свободная стартовая поляна. Пробежка — 60–130 единиц со скоростью 90 единиц/с. Проверяется прямой свободный путь с шагом не более 6 единиц; дерево дополнительно останавливает физическое тело. Если путь не найден или движение заблокировано, мышь останавливается и осматривается. Погони, атак и урона нет; с друидом мышь может пересекаться.

Связи: `data/mouse.ts` — размеры и числа; `rendering/mouseArt.ts` — кадры и темп; `behavior/MouseWander.ts` — выбор места и цикл состояний; `entities/Mouse.ts` — физика и отображение; `MeadowWorld` создаёт одну мышь и обновляет её после физического шага. Мышь не получает ссылку на игрока. R создаёт новую мышь с новой локацией; изменение размера окна её не пересоздаёт.
