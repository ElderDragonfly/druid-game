# Basic 04 на экране выбора персонажа

Новая сидящая поза основана на согласованном `druid-sprites-v1/druid-04-basic.png`: капюшон, седая заострённая борода, тёплый тёмный плащ, простая верёвка и обувь без шнурков. Обе пустые руки естественно лежат на коленях; голый посох лежит рядом на земле. [Композиция для просмотра](camp-preview.png).

**В игре это три независимых слоя, а не одна картинка:**

1. `camp-clean-plate.png` — окружение с пустым бревном.
2. `druid-seated.png` — прозрачная фигура выбранного друида.
3. `staff-lying.png` — отдельный прозрачный посох из `CharacterDefinition.camp.props`.

У всех слоёв общая сетка 696×864 и позиция (525,50) с масштабом 0,625. Фигура и посох не пересекаются. При выборе другого персонажа `chooseCharacter` заменяет фигуру и пересоздаёт только его предметы; пустой `props` убирает посох. Для предметов можно отдельно задавать позицию, масштаб и точку привязки; по умолчанию они наследуются от фигуры.

Прежний сидящий персонаж был частью непрозрачного фрагмента лагеря `druid-detail-preview-v1/character-selection-preview.png`. Из него взят точный `camp-reference.png`; под старой фигурой и вертикальным посохом восстановлено окружение. **За пределами `camp-edit-mask.png` пиксели фона дословно сохранены.** Главное меню, исходный Basic 04, портрет карточки и игровые спрайты не изменены. Старый утверждённый эскиз сохранён в прежней папке.

Нарисованные исходники — `seated-source.png` и `camp-clean-source.png`. `scripts/prepare-druid-basic-seated.py` изолирует фигуру/посох по отдельным компонентам, размещает их на общей сетке, удаляет внешнюю полупрозрачную кайму и собирает окружение только внутри маски. Для согласования с пиксельным лагерем используется сетка 2 нативных пикселя, NEAREST. `camp-preview.png` служит только просмотром и не используется вместо слоёв.

Технические размеры и границы слоёв: `art.json`. Подключение окружения/предмета: `selectionCampArt.ts`; фигура — `druidArt.ts`; выбор — `CharacterSelectScene` и `CharacterDefinition.camp`.
