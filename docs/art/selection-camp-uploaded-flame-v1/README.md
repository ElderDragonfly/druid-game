# Пламя из загруженной GIF

Источник пользователя сохранён в корне репозитория: `5b8606e6d60a88955aeda65edbd5a0fa62386d21.gif` (480×480, 37 кадров по 40 мс). **Используются все исходные фазы и их порядок: 25 FPS, цикл 1,48 с.** Новая анимация не генерировалась.

`scripts/prepare-uploaded-camp-flame.py` отделяет тёплые оранжевые/жёлтые пиксели пламени от тёмной клетчатой подложки и красно-белых поленьев исходника. Периодические линии сетки поверх самого пламени очищаются выборкой соседних настоящих пикселей огня; новых цветов не добавляется. Сохраняются исходные искры и форма каждой фазы. Это подготовка готового материала, а не перерисовка генератором.

Один масштаб 0,25 и одна позиция (6,22) применены ко всем исходным кадрам. Получается кадр 128×148 с опорой примерно (64,120); пламя соответствует прежнему размеру костра. `flame-only-frames.png` содержит только прозрачные фазы пламени. `fire-frames.png` — рабочий атлас 1024×740, сетка 8×5, последние три ячейки пустые. В игре регистрируются ровно 37 кадров с NEAREST.

Подложка `fire-base.png` дословно сохраняет пиксели согласованной основы из `selection-camp-frames-v1`. Камни, угли и окружение неподвижны во всех кадрах; ниже y=125 каждый пиксель совпадает с прежней основой. `fire-motion-mask.png` ограничивает новые языки/искры, `fire-change-mask.png` включает также прежнюю область очистки старого пламени. Вне неё сохраняются пиксели `fire-reference.png`.

Старые рисунки огня остаются в `selection-camp-frames-v1`, но больше не подключены. Вода, светлячки, фигура друида, посох и главное меню не изменены. Отдельная `fire-preview.gif` служит просмотром, в игре используются подготовленные PNG-кадры. Параметры — `art.json`.

Повторная подготовка: `python scripts/prepare-uploaded-camp-flame.py` (Python, Pillow, NumPy, SciPy). Исходная GIF и принятые материалы не перезаписываются.
