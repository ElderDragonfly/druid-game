# Проба ходьбы друида вниз: четыре полных позы

Второй вариант для обсуждения, пока без подключения к игре. Прежняя проба `druid-walk-down-v1` удалена.

- [Анимация для просмотра](walk-down-preview.gif).
- [Четыре исходные перерисованные фигуры](walk-down-source.png): лист 1254×1254, порядок чтения — слева направо, сверху вниз.
- [Полоса игровых кадров](walk-down-64x80.png): 256×80, четыре кадра по 64×80 слева направо.

Все позы смотрят вниз, к игроку. Посох остаётся в анатомически левой руке (справа для зрителя). Задание для рисунка включает шаг от таза, смену опорной ноги, движение плеч и рук, перенос и постановку посоха. Каждый кадр перерисован целиком: неподвижный торс поверх новых ног не накладывается, зеркальные копии частей тела не используются. Рисунок и убедительность шага предстоит оценить по превью.

Для всех фигур применяется общий масштаб 1/8. При подготовке кадров центр стоп совмещается с x=32, нижняя граница фигуры — с y=75. В результате непрозрачные пиксели заканчиваются на строке 74. PNG сохраняет прозрачность и цвета уменьшенного рисунка; альфа приводится к 0 или 255.

GIF показывает кадры в увеличении ×3 ближайшим соседом: 192×240, по 160 мс на кадр, цикл 640 мс. Ограничение палитры до 256 цветов относится только к GIF.

Код игры, действующие спрайты направлений и изображения меню не изменены.
