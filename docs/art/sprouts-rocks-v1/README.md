# Ростки и камни

Источник монстров: `../527076caeb6d25f73cacfbb20a55c730.jpg`, камней: `../162e3c85cb956a7c83640f8a76e839f2.jpg`. Подготовка: `python scripts/prepare-sprouts-rocks.py`.

Четыре целых монстра и девять камней вырезаны механически по внешнему фону. Цвета непрозрачных пикселей и замкнутые внутренние участки сохранены. В листе камней для каждой клетки удаляется только её собственный цвет фона: тёмный цвет соседней клетки совпадает с некоторыми бликами камней и удалять его нельзя. У монстров внешняя фиолетовая тень удалена вместе с фоном.

`plant-N.png` — отдельный слой только растительности для закопанного состояния; исходные целые фигуры сохранены в `sprout-N.png`. В референсе нет кадров движения. Выход из земли, низкие подскоки, подготовка и прыжок телом сделаны в игровом коде с раздельными рисунком и физическим телом. Никакие новые изображения нейросетью не генерировались.

`art.json` хранит рамки исходных фрагментов, размеры, нижнюю границу растительности и масштаб. У небольших шариков ширина около 44 игровых единиц, у большого 64; цветы добавляют высоту. Земляная прогалина рисуется один раз при создании поля, отдельной анимации и текстуры на каждый кадр нет.
