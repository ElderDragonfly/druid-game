# Ходьба вправо: предварительный вариант

Четыре фазы подготовлены **для просмотра, пока не подключены к игре**. В игре на D остаётся прежний стоящий ракурс.

- [Посмотреть движение в GIF](walk-right-preview.gif).
- [Четыре кадра, увеличенные ×7](walk-right-source.png).
- [Игровая полоса PNG 256×80](walk-right-64x80.png).

<img src="walk-right-preview.gif" alt="Четыре фазы ходьбы друида вправо" width="192">

Каждый кадр имеет сетку 64×80. Темп — 160 мс на фазу, полный цикл 640 мс; GIF показывает те же кадры с увеличением ×3 без сглаживания.

Порядок фаз: ближняя правая нога впереди → она поддерживает тело, дальняя левая проходит с поднятой стопой → дальняя левая впереди → она поддерживает тело, ближняя правая проходит с поднятой стопой. Ближняя нога светлее, дальняя темнее; это различие сохраняется при смене шага. Тело перерисовано для правого профиля, а не зеркально скопировано из левого цикла.

Посох сохраняется в **анатомически левой руке**. При взгляде на правый профиль это дальняя рука: слой рисуется за телом, и плащ/ноги могут естественно его перекрывать. Видимая ближняя правая рука свободна. Рука с посохом нарисована один раз и целиком смещается по вертикали на 0, −1, 0, +1 пиксель; её форма и цвета не меняются между фазами.

| Файл | Назначение |
| --- | --- |
| `walk-right-body-64x80.png` | Четыре фазы тела, ног и свободной ближней руки |
| `left-arm-staff-64x80.png` | Единственный слой дальней левой руки с посохом |
| `walk-right-layers.json` | Порядок слоёв, размеры, смещения и темп |
| `body-source.png` | Художественный исходник четырёх фаз тела |
| `arm-staff-source.png` | Художественный исходник единственного слоя руки и посоха |
| `source-layout.json` | Области исходников, общий масштаб и точки привязки при подготовке PNG |

Проверены прозрачность 0/255, четыре различных фазы ног, чередование светлой и тёмной ноги, точная композиция слоёв и неизменность видимых пикселей руки/посоха с учётом смещения и перекрытия телом. GIF имеет четыре кадра по 160 мс и общую палитру, чтобы неподвижные детали не меняли цвет. Художественное качество походки оцениваем по предпросмотру.
