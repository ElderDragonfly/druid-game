# Дерево очищения

Исходник: пользовательский `docs/art/1365d0f0558fb5103506f29ec1b13334.jpg`. `corrupted.png` — этот рисунок с удалённым белым фоном, приведённый без сглаживания к сетке 100×125. Палитра оставшихся исходных пикселей не заменяется. Спрайт в мире 200×250: один логический пиксель занимает 2 игровые единицы, близко к крупности рисунка окружения.

`cleansed-source.png` — отдельная дорисованная версия того же дерева с живой листвой. `cleansed.png` приведён к той же сетке, масштабу и опоре; прозрачность дискретная. Новая версия является перерисовкой очищенного состояния, а не точной копией коры исходника.

Подготовка обеих версий: `python scripts/prepare-room-art.py`. Коллизия задаётся отдельно, только у основания. Цветовых подсветок и кругов взаимодействия у основания нет; общий индикатор E расположен у друида.
