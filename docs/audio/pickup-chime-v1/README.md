# Короткий звук получения гриба

`pickup-chime.wav` — синтезированный восходящий «пинг», 0,32 секунды, PCM mono 44,1 кГц / 16 bit. Три мягких тона: 880, 1320 и 1760 Гц, быстрое вступление и плавное затухание. Записей из сторонних игр нет.

Воспроизводится один раз при сборе центрального гриба ведьминого круга. Следует текущему выключателю и уровню звука, коэффициент громкости 0,55; при заблокированном браузером аудио пропускается без отложенного проигрывания. Синтез повторяется командой `python scripts/prepare-mushroom-pickup.py`.
