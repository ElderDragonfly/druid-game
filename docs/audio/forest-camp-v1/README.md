# Музыкальный эскиз 01 — лесной лагерь

[Послушать/скачать MP3](forest-camp-loop.mp3) · [OGG для зацикливания](forest-camp-loop.ogg) · [Исходные ноты MIDI](forest-camp.mid)

Оригинальная тема для главного меню и выбора персонажа. Эскиз одобрен и подключён к обоим меню. Один трек продолжает играть при переходе между ними; во время игры он приостановлен. Кнопка динамика справа внизу и соседняя полоска громкости 0–100% запоминают свои настройки в браузере. Ползунок можно перетаскивать или щёлкнуть по нужному месту полоски; исходная громкость — 80%. Для веб-версии звук разблокируется первым кликом/клавишей.

45 секунд, 16 тактов, размер 6/8; четверть = 64 BPM (два неторопливых пульса на такт). Мягкие переборы нейлоновой гитары, редкая флейтовая мелодия, тихие протяжённые струны/виолончель и четыре светлых звука челесты. Ударных и звуков окружающей среды нет.

Основа — ре минор с открытыми созвучиями: Dm(add9) → B♭maj7 → Fmaj7 → Cadd9 → Gm(add9) → Dm/F → B♭maj7 → Asus4(add7,9). Основной мотив спускается A–G–F–E–D, затем получает короткие ответы выше; в конце остаётся пространство для возврата к началу.

Аудио подготовлено как цикл: 1 984 500 стереосэмплов при 44 100 Гц, без паузы или затухания в конце. Перед записью прошли два полных повтора, чтобы в начале сохранился хвост предыдущего. Для непосредственного повторения предпочтителен OGG: MP3-плееры могут по-разному обрабатывать задержку кодека. В MIDI тембр и реверберация зависят от проигрывателя.

Это программный инструментальный рендер для первого прослушивания. Ноты оригинальные; тембры взяты из установленного SoundFont TimGM6mb (Tim Brechbill / David Bolton, GPL-2). Сам SoundFont не включён в репозиторий. Источник сведений: `/usr/share/doc/timgm6mb-soundfont/copyright` в среде подготовки; [история SoundFont](https://github.com/musescore/musescore-old/commit/90c33ef9d87b3f5ff92efd3b07d89eb455fb1fef).

Повторная подготовка: `python scripts/compose-forest-camp.py --soundfont /путь/к/General-MIDI.sf2`. Нужны Python с NumPy/SciPy, libfluidsynth и FFmpeg; это только инструменты подготовки, зависимости игры не менялись. Скрипт хранит ноты, инструменты, аранжировку и настройки рендера.
