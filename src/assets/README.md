# Фоны меню

- `main-camp.png` — согласованная иллюстрация главного меню с друидом у костра.
- `selection-camp.png` — упрощённый пиксельный лагерь с пустым бревном. Сидящий персонаж рисуется отдельным игровым объектом, кнопки и текст тоже самостоятельны.

Оба изображения сгенерированы и включены в сборку. Композиция 16:9 вписана полностью в игровое поле, чтобы сохранять костёр, бревно и посох у правого края. Для замены фона измените соответствующий файл; загрузкой управляет `BootScene`.
