# Фоны и рабочий образ друида

- `main-camp.png` — прежняя согласованная иллюстрация главного меню с костром и исходным сидящим друидом. Восстановлена из версии до замены персонажа.
- `selection-camp.png` — упрощённый пиксельный лагерь с пустым бревном. Фон выбора сохраняет принятую композицию и пикселизацию.
- `characters/druid-standing-detail.png` — принятый первый вариант друида с исправленной связкой корешков; используется в ячейке выбора.
- `characters/druid-camp-source.png` — архив предыдущего прозрачного сидящего друида; сейчас не загружается.
- `characters/druid-game-source.png` — архив прежнего неподвижного игрового друида; сейчас не загружается.
- `docs/art/druid-turnaround-v3/druid-four-views.png` — одобренный подробный художественный оригинал; сейчас не загружается.
- `docs/art/druid-front-resolution-v1/druid-front-64x80.png` — выбранный и подключённый фронтальный игровой спрайт 64×80.
- `characters/druid-left-64x80.png`, `druid-right-64x80.png`, `druid-back-64x80.png` — три остальных ракурса 64×80, подготовленные из того же одобренного подробного листа.

Активный слой лагеря для выбранного друида берётся напрямую из `docs/art/druid-detail-preview-v1/character-selection-preview.png`, без дублирования файла. Кадр (840, 80), 696×864 исходных пикселей отображается в размере 435×540, в точке (525, 50). `druidArt.ts` копирует исходные пиксели без изменения палитры и сетки. В кадре находятся друид и окружение; прозрачного отделения этого конкретного образа пока нет.

Текст, портреты и кнопки меню рисуются отдельно. Слой лагеря, его масштаб и положение задаются через `CHARACTERS.camp`; игровой образ — через `CHARACTERS.game`. Для каждого направления загружается собственный PNG 64×80. `druidArt.ts` копирует их 1:1 в четыре слота атласа 256×80; источник каждого кадра задаётся в `DRUID_VIEWS.sourceKey`. Принятый фронтальный PNG не изменён. Остальные три изображения уменьшены тем же способом из соответствующих ракурсов одобренного подробного листа. Последние пять строк PNG прозрачны, поэтому копирование строк 0–74 сохраняет весь рисунок. Центр опоры x=32, нижняя граница ног y=75. Отображение кадра 87,5×109,375 и физическое тело 20×25 сохранены. `game.frames` связывает направления со слотами; `FourWayFacing` выбирает нужный ракурс по WASD, после остановки направление сохраняется. Сглаживание текстуры выключено.
