# Фоны и рабочий образ друида

- `main-camp.png` — прежняя согласованная иллюстрация главного меню с костром и исходным сидящим друидом. Восстановлена из версии до замены персонажа.
- `selection-camp.png` — упрощённый пиксельный лагерь с пустым бревном. Фон выбора сохраняет принятую композицию и пикселизацию.
- `characters/druid-standing-detail.png` — принятый первый вариант друида с исправленной связкой корешков; используется в ячейке выбора.
- `characters/druid-camp-source.png` — архив предыдущего прозрачного сидящего друида; сейчас не загружается.
- `characters/druid-game-source.png` — архив прежнего неподвижного игрового друида; сейчас не загружается.
- `docs/art/druid-turnaround-v3/druid-four-views.png` — одобренный подробный лист четырёх ракурсов, активный игровой источник.

Активный слой лагеря для выбранного друида берётся напрямую из `docs/art/druid-detail-preview-v1/character-selection-preview.png`, без дублирования файла. Кадр (840, 80), 696×864 исходных пикселей отображается в размере 435×540, в точке (525, 50). `druidArt.ts` копирует исходные пиксели без изменения палитры и сетки. В кадре находятся друид и окружение; прозрачного отделения этого конкретного образа пока нет.

Текст, портреты и кнопки меню рисуются отдельно. Слой лагеря, его масштаб и положение задаются через `CHARACTERS.camp`; игровой образ — через `CHARACTERS.game`. Игровой лист загружается напрямую без дублирования PNG. В `druidArt.ts` четыре фигуры копируются 1:1 в атлас 2048×640 с кадрами 512×640, без уменьшения сетки и палитры. Центр сапог выровнен на x=256, нижняя граница ног — y=600. Отображение кадра 87,5×109,375 и физическое тело 20×25 сохранены. `game.frames` связывает направления с кадрами; `FourWayFacing` выбирает их по WASD. Анимацию ходьбы и промежуточные повороты подготовим отдельным этапом.
